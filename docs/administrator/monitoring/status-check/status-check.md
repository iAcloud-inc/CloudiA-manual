# 상태 점검

**상태 점검 페이지**는 Cloud:iA 운영에 필요한 컨테이너와 서비스의 실행 상태를 주기적으로 점검하는 화면입니다.
각 대상의 상태를 한눈에 확인하고, 이상이 감지되면 원인과 권장 조치를 함께 제공합니다.
상태 점검 결과는 **읽기 전용**으로 제공됩니다.

## 화면 개요
- 자동 갱신 주기를 선택할 수 있으며, 기본값은 **30초**입니다.
- 점검 대상 목록이 상태와 함께 표시되고, 각 항목의 `상세 보기`에서 세부 내용을 확인합니다.

## 상태 점검 목록

점검 대상은 기본적으로 상태(심각도)값의 알파벳 순, 즉 `CRITICAL` → `OK` → `WARNING` 순으로 정렬됩니다. 심각도 우선순위(치명적인 것부터) 순서가 아니므로, `WARNING` 항목이 정상(`OK`) 항목보다 뒤에 표시될 수 있습니다. 필요하면 **상태** 컬럼을 클릭해 정렬 순서를 바꿀 수 있습니다.

> ⚠️ `WARNING` 항목이 다수의 `OK` 항목 뒤로 밀릴 수 있으니, 경고를 놓치지 않으려면 상태 컬럼 정렬을 활용하세요.

### 테이블 컬럼

| 컬럼명        | 설명                                              |
| ---------- | ----------------------------------------------- |
| **상태**     | 점검 결과를 `OK`, `WARNING`, `CRITICAL`로 표시합니다.      |
| **이름**     | 점검 대상 컴포넌트의 이름을 표시합니다.                          |
| **노드**     | 점검 대상이 배치된 노드를 표시합니다. 노드 정보가 없는 경우 `-`로 표시됩니다.  |
| **유형**     | 점검 대상이 컨테이너인지 서비스인지 표시합니다.                      |
| **점검 메시지** | 현재 상태로 판단된 원인이나 점검 결과를 표시합니다.                   |
| **점검 일시**  | 마지막 점검 시각을 로컬 시간 기준으로 표시합니다.                    |
| **상세 보기**  | `상세 보기`를 선택하면 점검 결과와 권고 사항을 상세 모달에서 확인할 수 있습니다. |


### 상태 값

| 상태           | 설명                                             |
| ------------ | ---------------------------------------------- |
| **OK**       | 점검 대상이 정상 상태이며 별도의 조치가 필요하지 않습니다.              |
| **WARNING**  | 일부 이상이 감지되어 상태 확인 또는 조치가 필요할 수 있습니다.           |
| **CRITICAL** | 서비스에 영향을 줄 수 있는 심각한 이상 상태로, 즉시 확인 및 조치가 필요합니다. |


### 점검 대상 컴포넌트

상태 점검은 Cloud:iA 운영에 필요한 주요 컴포넌트의 실행 상태를 확인합니다.

- **가상화 API 서버**
- **데이터베이스**
- **보안 API 서버**
- **웹 콘솔**
- **키 관리 서버(KMS)**
- **이중화 관리 서비스**
- **인증 서버**
- **원격 콘솔**
- **인가 정책 엔진**

### 점검 메시지

점검 결과에 따라 다음과 같은 메시지가 표시됩니다.

- 정상 실행 중입니다.
- 점검 명령이 실패했습니다.
- 컨테이너가 실행 중이 아닙니다.
- 호스트에 연결할 수 없습니다.
- 분류되지 않은 오류가 발생했습니다.

## 상세 보기

목록에서 **상세 보기**를 선택하면 해당 점검 대상의 상세 정보를 확인할 수 있습니다.

- **기본 정보**: 점검 대상의 이름, 노드, 유형, 상태 및 마지막 점검 일시를 확인할 수 있습니다.
- **점검 메시지**: 현재 상태로 판단된 원인과 점검 결과를 확인할 수 있습니다.
- **권장 조치**: 점검 결과에 따라 권장되는 조치 방법을 제공합니다. 이상이 없는 경우에는 별도의 조치가 필요하지 않음을 안내하며, 이상이 있는 경우에는 확인이 필요한 항목이나 권장 조치를 제공합니다.

> 💡 참고
> - 상태 점검 결과는 조회 전용이며, 점검 주기에 따라 자동으로 갱신됩니다.
> - 이상 상태가 발생한 경우 **상세 보기**에서 점검 메시지와 권장 조치를 확인하세요.
