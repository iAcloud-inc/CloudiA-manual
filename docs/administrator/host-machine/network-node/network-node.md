# 네트워크 노드

**네트워크 노드** 메뉴에서는 Cloud:iA의 네트워크를 담당하는 노드의 상태와 부하를 확인할 수 있습니다.
네트워크 노드 상세 화면에서는 가상 라우터, 서비스, 네트워크 인터페이스 정보를 탭으로 구분하여 제공합니다.

---

## 네트워크 노드 목록

네트워크 노드 목록 화면에서는 등록된 네트워크 노드의 상태와 부하를 한눈에 확인할 수 있습니다.

### 주요 작업

- **이름 클릭**: 선택한 네트워크 노드의 **상세 화면**으로 이동합니다.

> 💡 **참고:** 네트워크 노드 메뉴는 조회 전용입니다. 생성/수정/삭제 기능을 제공하지 않습니다.

### 테이블 컬럼

| 컬럼 | 설명 |
| --- | --- |
| **이름** | 네트워크 노드 이름입니다. 클릭 시 상세 화면으로 이동합니다. |
| **상태** | 현재 네트워크 노드 상태입니다. |
| **방화벽 규칙** | 노드에 적용된 방화벽 규칙이 설정과 일치하는지 주기적으로 대조한 결과입니다. |
| **가상 라우터 수** | 해당 노드에 배치된 가상 라우터의 수입니다. |
| **생성 일시** | 네트워크 노드가 등록된 일시입니다. |

> 💡 **참고:** 정렬은 `상태`와 `생성 일시` 컬럼에서만 제공합니다.

### 상태 이해하기

목록과 상세 화면에 표시되는 네트워크 노드 상태는 다음과 같습니다.
`실행 중`이 아닌 상태는 대부분 시스템이 자동으로 복구를 진행하는 중이며, 상세 화면에서 현재 어느 단계인지 안내 문구로 확인할 수 있습니다.

| 상태 | 의미 |
| --- | --- |
| **`실행 중`** | 노드가 정상 동작 중입니다. |
| **`이상 감지`** | 노드 이상을 감지해 자동 복구를 시작한 상태입니다. |
| **`정리 실패`** | 자동 복구 중 이전 설정을 정리하는 단계에서 막혀 재시도하고 있습니다. |
| **`이관 실패`** | 노드가 담당하던 가상 라우터를 다른 노드로 옮기지 못한 상태입니다. |
| **`망 이상`** | 설정 정리는 끝났고, 네트워크 점검 통과를 기다리는 중입니다. |
| **`유지관리 모드`** | 노드가 유지관리 모드입니다. 자동 복구와 재이관이 동작하지 않습니다. 자세한 내용은 [유지관리 모드](../machine/machine.md#유지관리-모드)를 참고하세요. |
| **`알 수 없음`** | 상태를 확인할 수 없습니다. |

### 방화벽 규칙 이해하기

| 값 | 의미 |
| --- | --- |
| **`동기화됨`** | 노드에 적용된 방화벽 규칙이 설정과 일치합니다. |
| **`어긋남 · 교정함`** | 설정과 다른 규칙을 발견해 자동으로 되돌렸습니다. |
| **`교정 실패`** | 설정과 다른 규칙을 발견했지만 되돌리지 못했습니다. 확인이 필요합니다. |
| **`확인 못 함`** | 아직 대조하지 않았거나, 마지막 대조 결과가 오래되어 신뢰할 수 없는 상태입니다. |

> 💡 **참고:** 대조한 적이 있는 노드는 값에 마우스를 올리면 마지막으로 대조한 시각을 확인할 수 있습니다.

## 네트워크 노드 상세

네트워크 노드 상세 화면은 상단 **정보 영역**과 하단 **탭 정보**로 구성됩니다.
상단 정보 영역은 기본 정보, 상태 정보 두 묶음으로 나뉩니다.

### 기본 정보

| 항목 | 설명 |
| --- | --- |
| **이름** | 네트워크 노드 이름입니다. |
| **가상 라우터 수** | 노드에 배치된 가상 라우터의 수입니다. |
| **생성 일시** | 네트워크 노드가 등록된 일시입니다. |

### 상태 정보

| 항목 | 설명 |
| --- | --- |
| **상태** | 네트워크 노드 운영 상태입니다. 목록의 상태와 같은 값입니다. |
| **Agent 연결 상태** | Host Agent 연결 상태를 표시합니다. |
| **네트워크 상태** | 네트워크 점검 결과를 표시합니다. |
| **방화벽 규칙** | 방화벽 규칙 대조 결과입니다. 목록의 방화벽 규칙과 같은 값입니다. |

#### 연결 상태 값

| 구분 | 값 | 의미 |
| --- | --- | --- |
| **Agent 연결 상태** | `연결됨` | Host Agent와 정상적으로 연결되어 있습니다. |
| | `연결 끊김` | Host Agent 연결이 끊겼습니다. |
| **네트워크 상태** | `정상` | 내부망과 외부망 점검이 모두 정상입니다. |
| | `내부만 정상` | 내부망 점검은 정상이고 외부망 점검은 정상이 아닙니다. |
| | `외부만 정상` | 외부망 점검은 정상이고 내부망 점검은 정상이 아닙니다. |
| | `에러` | 네트워크 점검이 정상이 아닙니다. |
| | `알 수 없음` | 네트워크 상태를 확인할 수 없습니다. |

> 💡 **참고:** 상태와 네트워크 상태는 점검 주기와 판단 기준이 서로 달라 다르게 보일 수 있습니다. 예를 들어 유지관리 모드에서는 네트워크 점검이 계속 정상이어도 상태는 `유지관리 모드`로 유지됩니다.

### 상태 안내 문구

상태가 `이상 감지`, `정리 실패`, `망 이상`, `유지관리 모드`이면 상태 정보 영역 아래에 현재 진행 상황을 설명하는 안내 문구가 표시됩니다.
자동 복구를 기다리면 되는 상태인지, 직접 확인이 필요한 상태인지 판단할 때 참고합니다.

> 💡 **참고:** `실행 중`과 `이관 실패`는 안내 문구가 표시되지 않습니다.

### 탭 구성

#### 가상 라우터

현재 네트워크 노드에 배치된 가상 라우터 목록을 제공합니다.

| 컬럼 | 설명 |
| --- | --- |
| **VPC** | 가상 라우터가 속한 VPC 이름입니다. |
| **ID** | 가상 라우터 ID입니다. |
| **상태** | 가상 라우터 상태입니다. |
| **프로젝트** | VPC를 소유한 프로젝트 이름입니다. |
| **외부 IP 수** | 해당 VPC가 사용 중인 외부 IP의 수입니다. |
| **생성 일시** | VPC 생성 일시입니다. |

##### 가상 라우터 상태 값

| 상태 | 의미 |
| --- | --- |
| **`정상`** | 가상 라우터가 정상 동작 중입니다. |
| **`생성 중`** | 가상 라우터를 준비하고 있습니다. |
| **`이관 중`** | 가상 라우터를 다른 노드로 옮기고 있습니다. |
| **`이상 감지`** | 이상을 감지해 자동 복구를 진행 중입니다. |
| **`삭제 실패`** | 가상 라우터 삭제가 완료되지 않았습니다. 확인이 필요합니다. |
| **`알 수 없음`** | 상태를 확인할 수 없습니다. |

#### 서비스

현재 네트워크 노드가 담당하는 서비스 컨테이너(DNS, 로드 밸런서) 목록을 제공합니다.

| 컬럼 | 설명 |
| --- | --- |
| **이름** | 컨테이너 이름입니다. |
| **유형** | `DNS` 또는 `로드 밸런서`입니다. |
| **상태** | 컨테이너 동작 상태입니다. |
| **VPC** | 컨테이너가 속한 VPC 이름입니다. |
| **프로젝트** | VPC를 소유한 프로젝트 이름입니다. |
| **생성 일시** | 컨테이너 생성 일시입니다. |

##### 컨테이너 상태 값

| 상태 | 의미 |
| --- | --- |
| **`정상`** | 컨테이너가 정상 동작 중입니다. |
| **`복구 중…`** | 이상을 감지해 자동 복구를 진행 중입니다. |
| **`이상 감지`** | 컨테이너가 정상 동작하지 않습니다. 확인이 필요합니다. |
| **`삭제 중`** | 컨테이너 삭제가 진행 중입니다. |
| **`알 수 없음`** | 상태를 확인할 수 없습니다. |

> 💡 **참고:** 상태 값에 마우스를 올리면 원래 상태값을 확인할 수 있습니다. `이상 감지`와 `복구 중…`은 기록된 실패 사유도 함께 표시됩니다.

#### 네트워크 인터페이스

현재 네트워크 노드의 망 구성을 망 단위로 제공합니다. 망 한 개가 한 행으로 표시되며, 구성되지 않은 망은 표시되지 않습니다.

| 컬럼 | 설명 |
| --- | --- |
| **용도** | 망의 용도입니다. `내부망`, `외부망`, `관리망`, `스토리지 서비스망`, `스토리지 복제망` 중 하나입니다. |
| **물리 인터페이스** | 망이 사용하는 물리 네트워크 인터페이스입니다. 본딩이 구성되어 있으면 본딩 이름 뒤에 묶인 인터페이스가 괄호 안에 표시됩니다. |
| **브리지** | 망에 연결된 브리지 이름입니다. |
| **IP / CIDR** | 망에 할당된 IP 주소와 대역입니다. |
| **게이트웨이** | 망의 게이트웨이 주소입니다. |
| **DNS** | 망에 설정된 DNS 주소입니다. |

> 💡 **참고:** 값이 없는 항목은 `-`로 표시됩니다.
