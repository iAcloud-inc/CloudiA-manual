## 모든 노드

모든 노드 패널에서는 클러스터에 등록된 전체 물리 노드 현황을 요약하여 보여줍니다. 
총 노드 수와 정상/비정상 노드 수를 한눈에 확인할 수 있으며, 패널 우측 상단의 [더보기] 버튼을 통해 노드 관리 페이지로 이동할 수 있습니다.

### 요약 정보

Cloud:iA에 등록된 **전체 물리 노드 현황**을 요약한 영역이며, `더보기 >` 클릭 시 **노드 관리 페이지**로 이동합니다.

### 테이블 컬럼
| 항목      | 설명                       |
| ------- | ------------------------ |
| **전체**  | 등록된 전체 물리 노드 수입니다.       |
| **정상**  | 현재 정상 상태의 노드 수입니다.       |
| **비정상** | 통신 불가 등 문제가 발생한 노드 수입니다. |

## 매니지먼트

### 요약 정보
**매니지먼트** 패널은 CloudiA 시스템을 운영하는 **매니지먼트 노드들의 상태 정보**를 제공합니다. 매니지먼트 노드의 호스트명과 현재 상태를 한눈에 확인할 수 있으며, 상태에 따라 색상 적용됩니다.

패널에는 이중화 환경 구성에 따라 **1개 또는 2개의  노드**가 카드 형태로 표시됩니다.

### 테이블 컬럼

| 컬럼 | 설명 |
|------|------|
| **호스트명** | 관리 노드의 이름입니다. 시스템 운영의 핵심 노드이며, 구성에 따라 하나 또는 두 개가 표시됩니다. |
| **상태** | 현재 운영 상태를 표시합니다. 정상일 경우 초록색 **“정상”**, 문제가 있을 경우 빨간색 **“비정상”**으로 표시됩니다. |

## CPU

### CPU 자원 요약

모든 노드의 **평균 부하 / 전체 코어** 비율을 원형 차트로 제공합니다. 차트 가운데에는 사용률(%)과 `평균 부하 / 전체` 코어 수가 함께 표시됩니다.

### 사용률 상위 5

CPU 사용률이 높은 노드 순위를 보여주는 리스트입니다. 순위 기준은 `평균 부하 / 전체` 비율입니다.

| 항목                  | 설명                                      |
| ------------------- |-----------------------------------------|
| **호스트명**            | 노드 이름이며 클릭 시 해당 노드 상세 화면으로 이동합니다.       |
| **사용률(%)**          | 전체 코어 대비 평균 부하 비율이며, 수준별 색상(녹색/황색/적색)으로 표시됩니다. |
| **평균 부하 / 전체 코어** | 노드의 평균 부하와 총 코어 수를 보여줍니다.            |

### 색상 기준

| 구간          | 의미 |
|-------------|----|
| **0~60%**   | 안전 |
| **61~80%**  | 주의 |
| **81~100%** | 위험 |

### 사용률 추이 그래프

* “**CPU 최근 24시간 기준 사용량 (단위: 1시간)**” 그래프 제공
* 최근 24시간의 전체 CPU 사용률 변화를 1시간 단위로 표시
* **80% 임계선** 포함
* 마우스 오버 시 시점별 상세 수치 확인 가능

## 메모리

### 메모리 자원 요약

CPU 패널과 동일한 구성으로 클러스터 전체 메모리 사용량을 제공합니다. 차트 가운데에는 사용률(%)과 `사용 중 / 전체` 용량이 함께 표시됩니다.

#### 사용률 상위 5

메모리 사용률 상위 5개 노드를 표시합니다. 순위 기준은 `사용 중 / 전체` 비율입니다.

| 항목                  | 설명                      |
| ------------------- |-------------------------|
| **호스트명**            | 노드 이름이며 클릭 시 해당 노드 상세 화면으로 이동합니다. |
| **사용률(%)**          | 메모리 사용률이며, 수준별 색상(녹색/황색/적색)으로 수준 표시됩니다. |
| **사용 메모리 / 전체 메모리** | 사용 중 용량 및 전체 메모리 용량입니다. |

#### 색상 기준

| 구간          | 의미 |
|-------------|----|
| **0~60%**   | 안전 |
| **61~80%**  | 주의 |
| **81~100%** | 위험 |

#### 사용률 추이 그래프

* “**메모리 최근 24시간 기준 사용량 (단위: 1시간)**” 그래프 제공
* 최근 24시간의 전체 메모리 사용률 변화를 1시간 단위로 표시
* 80% 기준선 포함
* 마우스 오버로 세부 수치 확인 가능

## 이벤트

### 기간별 집계 카드

**이벤트** 패널 상단에는 기간별 집계 카드 두 묶음이 표시됩니다. 각 묶음의 `더보기 >`를 선택하면 해당 조건으로 걸러진 이벤트 목록 화면으로 이동합니다.

| 항목 | 설명 |
| --- | --- |
| **페일오버 발생 수** | 기간별 페일오버 발생 건수입니다. 1건 이상이면 카드가 붉은색으로 표시됩니다. |
| **ERROR 이벤트 수** | 기간별 ERROR 등급 이벤트 건수입니다. |

* 카드마다 집계 기간이 라벨로 표시되며, 표시되는 기간은 시스템 설정에 따릅니다.
* **페일오버 발생 수**는 툴팁에서 집계 대상을 확인할 수 있습니다. 컴퓨트 노드 페일오버(해당 노드에 속한 모든 인스턴스 대상)와 Cloud:iA 페일오버(매니지먼트 노드에서 발생)를 합산한 값입니다.

### 최근 이벤트 목록

시스템에서 발생한 최근 **이벤트 최대 5개**가 표시됩니다.

| 항목         | 설명                        |
| ---------- | ------------------------- |
| **이벤트 이름** | 발생한 이벤트의 이름입니다. |
| **사용자**    | 이벤트를 발생시킨 사용자명입니다.      |
| **메시지**     | 이벤트 메시지 요약입니다.            |
| **발생 일시**     | 이벤트 발생 시각입니다.             |

* 좌측 아이콘 색상으로 등급 표시
* 등급 범례는 **INFO / WARN / ERROR / CRITICAL** 4단계이며, ERROR 와 CRITICAL 은 서로 다른 색으로 구분됩니다
* `더보기 >` 선택 시 이벤트 전체 목록 페이지 이동

## 감사 로그

### 최근 감사 로그 목록

최근 **감사 로그 6건**이 표시되며, 사용자 활동 및 자원 조작 기록을 제공합니다.

| 항목             | 설명                          |
| -------------- | --------------------------- |
| **사용자**        | 작업을 수행한 사용자명입니다.             |
| **메시지** | 어떤 자원에 어떤 작업이 수행되었는지 표시합니다. |
| **상태(성공/실패)**  | 성공은 녹색, 실패는 붉은색으로 표시됩니다.    |
| **발생 일시**         | 작업 수행 시각입니다.                |

* 감사 로그 메시지 클릭 시 **감사 로그 상세 화면**으로 이동
* 상단의 `더보기 >` 선택 시 전체 목록 화면으로 이동

## 자동 갱신

### 요약 정보

- 기본 자동 갱신 주기는 5초입니다.
- 자동 갱신 주기는 **꺼짐, 5초, 10초, 30초, 1분, 5분, 15분, 30분, 1시간** 중에서 선택할 수 있습니다.
- 새로고침 버튼 클릭 시 즉시 최신 데이터를 다시 조회합니다.
- 마지막 갱신 시각을 함께 제공합니다.
