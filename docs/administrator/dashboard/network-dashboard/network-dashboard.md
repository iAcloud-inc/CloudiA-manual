# 네트워크 대시보드

**네트워크 대시보드**(대시보드 → `네트워크 노드` 탭)는 Cloud:iA의 네트워크 노드 상태와 가상 라우터 분포, 외부망·내부망 트래픽을 한눈에 확인하는 화면입니다.

네트워크 노드와 가상 라우터의 상태 요약, 패킷 손실, 망별 트래픽 추이와 노드별 트래픽량, 가상 라우터 배치, 노드별 네트워크 사용률, 노드별 가상 라우터 현황을 통합해서 제공합니다.

패널마다 보여 주는 값의 시간 범위가 다릅니다. 패널 제목 오른쪽에 `최근 24시간`이 적힌 패널(**패킷 손실**, **트래픽량 상위 5**)은 지난 24시간을 합한 값입니다. **트래픽 추이**는 그래프의 가로축이 최근 24시간이라 따로 표시하지 않습니다. 나머지 패널은 현재 값입니다. 상태·개수·배치는 지금 상태 그대로이고, 속도·사용률 지표(**네트워크 사용률**, 노드별 가상 라우터 현황의 타일 툴팁)는 최근 1분 평균입니다.

---

## 네트워크 노드 상태

### 요약 정보

네트워크 노드 상태 패널에서는 등록된 네트워크 노드의 전체/정상/비정상 수를 확인할 수 있습니다.
패널 우측 상단의 [**더보기**] 버튼을 클릭하면 네트워크 노드 관리 페이지로 이동합니다.

### 테이블 컬럼

| 항목      | 설명                                        |
|---------|-------------------------------------------|
| **전체**  | 등록된 네트워크 노드 수입니다.                         |
| **정상**  | 현재 정상 상태의 노드 수입니다.                        |
| **비정상** | 정상 상태가 아닌 노드 수입니다. 1 이상이면 카드가 빨간색으로 표시됩니다. |

---

## 패킷 손실

### 요약 정보

패킷 손실 패널은 최근 24시간 동안 모든 네트워크 노드의 외부망·내부망 NIC에서 버려진 패킷 수를 **드롭**과 **에러**로 나누어 보여 줍니다. 관리망·스토리지망 NIC는 포함하지 않습니다.
방화벽이나 보안 그룹이 막은 패킷은 포함하지 않습니다.

### 테이블 컬럼

| 항목     | 설명                                                |
|--------|---------------------------------------------------|
| **드롭** | 외부망·내부망 NIC가 버린 패킷 수입니다. 1 이상이면 주의 색으로 표시됩니다.  |
| **에러** | 외부망·내부망 NIC에서 오류로 처리된 패킷 수입니다. 1 이상이면 위험 색으로 표시됩니다.    |

> 💡 **참고:** 드롭·에러가 계속 늘어나면 네트워크 노드 상세 화면에서 어느 노드의 어느 망(외부망·내부망)에서 발생하는지 확인하세요.

---

## 가상 라우터 상태

### 요약 정보

가상 라우터 상태 패널에서는 전체 가상 라우터의 전체/정상/비정상 수를 확인할 수 있습니다. 가상 라우터는 VPC 하나에 하나씩 네트워크 노드에 배치됩니다.

### 테이블 컬럼

| 항목      | 설명                                                |
|---------|---------------------------------------------------|
| **전체**  | 생성된 가상 라우터 수입니다.                                  |
| **정상**  | 정상 또는 생성 중인 가상 라우터 수입니다.                          |
| **비정상** | 이상 감지, 삭제 실패, 페일오버 진행 중, 알 수 없음 상태의 가상 라우터 수입니다. 1 이상이면 카드가 빨간색으로 표시됩니다. |

---

## 가상 라우터 배치

### 요약 정보

가상 라우터 배치 패널은 가상 라우터가 어느 네트워크 노드에 몇 개 배치되어 있는지 원형 차트와 목록으로 보여 줍니다.
차트 가운데에는 전체 가상 라우터 수가 표시되고, 오른쪽 `노드` 목록은 가상 라우터가 많은 순으로 정렬됩니다.

차트 조각에 마우스를 올리면 그 노드의 가상 라우터 수와 전체 대비 비율이 표시됩니다. 목록의 노드명을 클릭하면 해당 네트워크 노드 상세 화면으로 이동합니다.

| 항목             | 설명                        |
|----------------|---------------------------|
| **노드**         | 네트워크 노드 이름입니다.            |
| **가상 라우터 수**   | 해당 노드에 배치된 가상 라우터 수입니다.   |

---

## 네트워크 사용률

### 요약 정보

네트워크 사용률 패널은 네트워크 노드별로 **외부망**과 **내부망**의 수신·송신 사용률(%)을 보여 줍니다.
사용률은 물리 NIC의 링크 속도 대비 1분 평균 속도이며, 최대 2분 지연될 수 있습니다. 사용률이 높은 노드부터 최대 5개를 표시합니다.

노드명에 마우스를 올리면 상세 정보가 표시되고, 클릭하면 해당 네트워크 노드 상세 화면으로 이동합니다.

### 테이블 컬럼

| 항목            | 설명                                         |
|---------------|--------------------------------------------|
| **노드**        | 네트워크 노드 이름입니다.                             |
| **외부망 수신/송신** | 외부망 NIC의 링크 속도 대비 수신·송신 사용률(%)입니다.         |
| **내부망 수신/송신** | 내부망 NIC의 링크 속도 대비 수신·송신 사용률(%)입니다.         |

### 노드 상세 정보 확인

| 항목          | 설명                                              |
|-------------|-------------------------------------------------|
| **이름**      | 네트워크 노드 전체 이름입니다.                               |
| **링크 속도**   | 외부망·내부망 NIC의 링크 속도입니다. 예: `외부망 10G · 내부망 10G`     |
| **외부망**     | 외부망의 수신·송신 속도(최근 1분 평균)와 사용률입니다. 예: `수신 1.20 Gbps (12%) · 송신 300 Mbps (3.0%)` |
| **내부망**     | 내부망의 수신·송신 속도(최근 1분 평균)와 사용률입니다.                 |
| **CPU**     | 노드의 CPU 사용률입니다.                                 |
| **메모리**     | 노드의 메모리 사용률입니다.                                 |

### 색상 기준

| 구간          | 의미 |
|-------------|----|
| **0~59%**   | 안전 |
| **60~79%**  | 주의 |
| **80~100%** | 위험 |

> 💡 **참고:** 링크 속도를 알 수 없는 NIC(가상 NIC 등)는 사용률이 `—`로 표시됩니다. 이 경우 툴팁의 수신·송신 속도는 표시되지만 사용률(%)은 비어 있습니다. 수집이 끊긴 노드는 속도와 사용률이 모두 `—`로 표시됩니다.

## 트래픽 추이

### 요약 정보

트래픽 추이 패널은 모든 네트워크 노드의 수신·송신 속도를 **외부망**과 **내부망**으로 나누어 더한 값의 최근 24시간 추이를 선 그래프로 보여 줍니다.
두 그래프는 같은 세로축 범위를 쓰므로 외부망과 내부망의 크기를 바로 비교할 수 있습니다.

그래프에 마우스를 올리면 그 시각의 수신·송신 속도가 표시됩니다.

| 항목            | 설명                                           |
|---------------|----------------------------------------------|
| **수신**        | 모든 네트워크 노드가 해당 망에서 받은 속도의 합입니다.              |
| **송신**        | 모든 네트워크 노드가 해당 망으로 보낸 속도의 합입니다.              |
| **가로축**       | `24시간 전`부터 직전에 끝난 1시간 구간까지, 1시간 단위 24개 구간입니다. 진행 중인 현재 1시간은 포함하지 않습니다.          |

> 💡 **참고:** 한 패킷이 내부망으로 들어와 외부망으로 나가면 두 망에 모두 집계됩니다. 외부망과 내부망 값을 다시 더해서 읽지 마세요.

---

## 트래픽량 상위 5

### 요약 정보

트래픽량 상위 5 패널은 최근 24시간 동안 트래픽을 가장 많이 처리한 네트워크 노드를 **외부망**과 **내부망** 각각 최대 5개까지 보여 줍니다.
순위 기준은 최근 24시간 수신+송신 누적량이며, 값은 `수신 / 송신` 순서로 표시됩니다. 노드명을 클릭하면 해당 네트워크 노드 상세 화면으로 이동합니다.

| 항목            | 설명                                                 |
|---------------|----------------------------------------------------|
| **노드**        | 네트워크 노드 이름입니다.                                     |
| **수신 / 송신**   | 최근 24시간 누적 수신량과 송신량입니다. 예: `1.20 TB / 340.00 GB`        |

> 💡 **참고:** 트래픽 추이는 속도(bps), 트래픽량 상위 5는 누적량(바이트)입니다. 네트워크 사용률은 현재 값이므로 "지금 바쁜 노드"는 네트워크 사용률에서, "최근 24시간 동안 많이 처리한 노드"는 트래픽량 상위 5에서 확인하세요.

---

## 노드별 가상 라우터 현황

### 요약 정보

노드별 가상 라우터 현황 패널에서는 각 네트워크 노드에 배치된 가상 라우터를 육각 타일 형태로 표시합니다.
노드 이름 옆에는 해당 노드의 가상 라우터 수가 `가상 라우터 N`으로, 오른쪽 끝에는 노드 상태가 표시됩니다.
노드명을 클릭하면 해당 네트워크 노드 상세 화면의 가상 라우터 탭으로 이동할 수 있습니다. 패널 우측 상단의 [**더보기**] 버튼을 클릭하면 네트워크 노드 관리 페이지로 이동합니다.

### 상태

| 범례      | 포함 상태                              |
|---------|------------------------------------|
| **정상**  | 정상, 생성 중                           |
| **비정상** | 이상 감지, 삭제 실패, 페일오버 진행 중, 알 수 없음   |

노드 상태는 정상, 이상 감지, 정리 실패, 페일오버 실패, 망 이상, 유지관리 중으로 표시됩니다.

### 가상 라우터 상세 정보 확인

가상 라우터 타일에 마우스를 올리면 해당 가상 라우터의 상세 정보가 표시됩니다. 속도·패킷은 최근 1분 평균이고, 연결 수는 최근 1분 구간의 최댓값입니다.

| 항목         | 설명                                                                  |
|------------|---------------------------------------------------------------------|
| **이름**     | 가상 라우터가 속한 VPC 이름과 가상 라우터 ID를 함께 표시합니다. 예: `vpc-a (ID: 12)`          |
| **프로젝트**   | 가상 라우터가 속한 프로젝트 이름과 프로젝트 ID를 함께 표시합니다.                              |
| **상태**     | 가상 라우터의 현재 상태입니다.                                                   |
| **외부망**    | 인터넷 쪽 수신·송신 속도입니다. 수신은 인터넷에서 VPC로 들어오는 방향입니다. 예: `수신 12 Mbps / 송신 300 Kbps` |
| **내부망**    | 컴퓨트 노드 쪽 수신·송신 속도입니다.                                               |
| **패킷**     | 외부망·내부망을 합한 초당 수신·송신 패킷 수입니다.                                       |
| **연결 수**   | 가상 라우터가 추적 중인 연결 수입니다. 노드 상한을 알 수 있으면 `연결 수 / 상한 (비율%)`으로 표시합니다.       |
| **생성 일시**  | 가상 라우터가 속한 VPC의 생성 시각입니다.                                            |

### 참고 사항

- 노드당 최대 14개 가상 라우터 타일을 표시합니다.
- 가상 라우터가 많을 경우 마지막 타일에 `···`가 표시되며 클릭 시 해당 노드 상세 화면의 가상 라우터 탭으로 이동합니다.
- 가상 라우터가 없는 노드에는 `해당 노드에 가상 라우터가 존재하지 않습니다.`가 표시됩니다.
- 그 1분 구간에 지표가 없는 가상 라우터는 속도·패킷·연결 수가 `—`로 표시됩니다.

## 자동 갱신

### 요약 정보

- 기본 자동 갱신 주기는 5초입니다.
- 자동 갱신 주기는 **꺼짐, 5초, 10초, 30초, 1분, 5분, 15분, 30분, 1시간** 중에서 선택할 수 있습니다.
- 새로고침 버튼 클릭 시 즉시 최신 데이터를 다시 조회합니다. 조회 중에는 새로고침 버튼이 비활성화되고, 모든 패널의 조회가 끝나면 다시 활성화됩니다.
- 마지막 갱신 시각을 함께 제공합니다.
