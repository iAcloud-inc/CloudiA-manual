# 컴퓨트 대시보드

**컴퓨트 대시보드**는 Cloud:iA의 컴퓨트 노드 상태와 인스턴스 분포를 한눈에 확인하는 화면입니다.

전체 노드 상태 요약, CPU/메모리 할당 현황, 노드별 인스턴스 상태를 통합해서 제공합니다.
CPU와 메모리 모두 원형 차트 가운데에 새 인스턴스에 더 내줄 수 있는 **배치 가능 여유**를 크게 보여 줍니다.

---

## 컴퓨트 노드 상태

### 요약 정보

컴퓨트 노드 상태 패널에서는 등록된 컴퓨트 노드의 전체/정상/비정상 수를 확인할 수 있습니다.
패널 우측 상단의 [**더보기**] 버튼을 클릭하면 컴퓨트 노드 관리 페이지로 이동합니다.

### 테이블 컬럼

| 항목      | 설명                 |
|---------|--------------------|
| **전체**  | 등록된 컴퓨트 노드 수입니다.   |
| **정상**  | 현재 정상 상태의 노드 수입니다. |
| **비정상** | 정상 상태가 아닌 노드 수입니다. 1 이상이면 카드가 빨간색으로 표시됩니다. |

---

## CPU

### CPU 자원 요약

CPU 패널은 컴퓨트 노드의 전체 vCPU 대비 인스턴스에 할당된 vCPU 비율을 원형 차트로 제공합니다. 전체 vCPU는 노드의 CPU 스레드 수에 CPU 오버커밋 비율을 곱한 값입니다. 원형 차트 가운데에는 `배치 가능 여유`(전체 − 할당)가 크게, 그 아래에 `할당률`과 `전체 <값> vCPU`가 작게 표시됩니다.

원형 차트에 마우스를 올리면 할당량과 노드당 최대 여유가 표시됩니다. CPU 오버커밋 비율을 1보다 크게 둔 노드가 있으면 물리 스레드 수도 함께 표시됩니다. 배치 가능 여유는 노드별 여유를 더한 값이라, 인스턴스 한 대가 받을 수 있는 최대 크기는 **노드당 최대 여유**로 확인합니다.

### 할당률 상위 5

CPU 할당 비율이 높은 상위 5개 컴퓨트 노드를 목록으로 제공합니다.
노드명을 클릭하면 해당 컴퓨트 노드 상세 화면으로 이동합니다.

| 항목                | 설명                      |
|-------------------|-------------------------|
| **노드명**           | 컴퓨트 노드 이름입니다.           |
| **할당률(%)**        | 전체 vCPU 대비 할당된 vCPU 비율입니다.   |
| **할당 / 전체 (vCPU)** | 할당된 vCPU 수와 전체 vCPU 수입니다. |

### 색상 기준

| 구간          | 의미 |
|-------------|----|
| **0~60%**   | 안전 |
| **61~80%**  | 주의 |
| **81~100%** | 위험 |

## 메모리

### 메모리 자원 요약

메모리 패널은 컴퓨트 노드의 물리 메모리 전체를 원형 차트로 제공합니다. 원형 차트 가운데에는 새 인스턴스에 더 내줄 수 있는 `배치 가능 여유`가 크게 표시되고, 그 아래에 `할당률`, `할당 가능 <값>`, `물리 <값>`이 작게 표시됩니다. 원 색은 물리가 아니라 할당 가능 메모리 대비 할당률을 따릅니다. 배치 가능 여유는 할당 가능 메모리에서 할당량(인스턴스의 보장 메모리와 가상화 오버헤드의 합)을 뺀 값입니다.

원형 차트는 12시 방향부터 시계 방향으로 다음 네 부분으로 나뉩니다. 차트에 마우스를 올리면 네 값이 같은 순서로 툴팁에 표시되고, 그 아래에 인스턴스 한 대가 받을 수 있는 **노드당 최대 여유**가 표시됩니다. 패널 제목 옆 안내 아이콘에는 원의 빗금·회색이 무엇인지와, 할당량·할당률 상위 5의 기준이 표시됩니다.

| 구분 | 설명 |
|---|---|
| **시스템 예약** | 운영체제와 관리 서비스용으로 남겨 둔 메모리(물리 − 할당 가능)입니다. 인스턴스에 내줄 수 없으며 진한 회색 빗금으로 표시합니다. |
| **보장 메모리** | 인스턴스에 보장한 메모리의 합입니다. 상태 색상으로 표시됩니다. |
| **오버헤드** | 인스턴스를 실행하는 데 드는 가상화 오버헤드입니다. 보장 메모리와 같은 색을 옅게 표시합니다. |
| **미할당** | 아직 인스턴스에 할당하지 않은 나머지 메모리입니다. |

### 할당률 상위 5

메모리 할당 비율이 높은 상위 5개 컴퓨트 노드를 목록으로 제공합니다.
노드명을 클릭하면 해당 컴퓨트 노드 상세 화면으로 이동합니다.

| 항목                  | 설명                       |
|---------------------|--------------------------|
| **노드명**             | 컴퓨트 노드 이름입니다.            |
| **할당률(%)**          | 할당 가능 메모리 대비 할당량의 비율입니다.  |
| **할당량 / 할당 가능 메모리** | 할당량과 할당 가능 메모리 용량입니다. 시스템 예약은 인스턴스가 쓸 수 없어 분모에 넣지 않습니다. |

### 색상 기준

| 구간          | 의미 |
|-------------|----|
| **0~60%**   | 안전 |
| **61~80%**  | 주의 |
| **81~100%** | 위험 |

## 노드별 인스턴스 현황

### 요약 정보

노드별 인스턴스 현황 패널에서는 각 컴퓨트 노드에 배치된 인스턴스를 육각 타일 형태로 표시합니다.
노드명을 클릭하면 해당 컴퓨트 노드 상세 화면의 인스턴스 탭으로 이동할 수 있습니다.

### 상태

| 범례       | 포함 상태                                                          |
|----------|----------------------------------------------------------------|
| **실행 중** | 실행 중                                                           |
| **주의**   | 부팅 중, 종료 중, 생성 중, 삭제 중, 재부팅 중, 업데이트 중(라이브 업데이트 포함), 마이그레이션 중, 스냅샷 처리 중 |
| **에러**   | 에러(에러로 정지·호스트 자원 부족·배치 불일치), 일시 중지      |
| **정지**   | 종료됨, 정지됨                                                       |

### 인스턴스 상세 정보 확인

인스턴스 타일에 마우스를 올리면 해당 인스턴스의 상세 정보가 표시됩니다.

| 항목 | 설명 |
|---|---|
| **이름** | 인스턴스 이름과 인스턴스 ID를 함께 표시합니다. 예: `vm-01 (ID: 115)` |
| **프로젝트** | 인스턴스가 속한 프로젝트 이름과 프로젝트 ID를 함께 표시합니다. 예: `project-a (ID: 35)` |
| **상태** | 인스턴스의 현재 상태입니다. |
| **vCPU / 메모리** | 할당된 vCPU 수와 메모리 크기입니다. 예: `32 GB` |
| **AI 가속기** | 인스턴스에 할당된 GPU/NPU를 모델명과 수량으로 표시합니다. 예: `NPU RBLN-CA25 (PF) ×1`. 할당된 가속기가 없으면 `-`로 표시됩니다. |
| **보안 유형** | 보안(암호화) 인스턴스 유형입니다. |
| **IP 주소** | 인스턴스에 할당된 IP 주소입니다. |
| **생성 일시 / 수정 일시** | 인스턴스 생성·수정 시각입니다. |
| **UUID** | 인스턴스의 고유 식별자입니다. |

### 예외 상태 설명

| 상태 코드             | 설명                                                                 |
|------------------|--------------------------------------------------------------------|
| **NODE_MISMATCH** | 배치 정합성이 일치하지 않는 상태입니다. 즉, 배치 정보(Placement DB)에 기록된 노드와 가상머신이 실제로 실행 중인 노드가 서로 다른 상태로, **시스템이 자동으로 복구를 진행**합니다. |
| **SCHEDULE_FAILED** | 페일오버(장애 복구) 재배치 시점에 스케줄 가능한 컴퓨트 노드가 없어 배치에 실패한 상태입니다. 스케줄 가능한 노드가 생기면 자동으로 재스케줄을 시도하며, 스토리지 도메인/파일 시스템/선호도 그룹 등으로 특정 노드에 전용된 경우에는 해당 노드가 정상화되면 그 노드로 자동 복구됩니다. |

### 참고 사항

- 정상 상태의 컴퓨트 노드만 노드별 인스턴스 현황 패널에 표시됩니다.
- 노드 이름 옆에는 해당 노드에 배치된 인스턴스 수가 `인스턴스 N` 형태로 표시됩니다.
- 노드당 최대 21개 인스턴스 타일을 표시합니다.
- 인스턴스가 많을 경우 마지막 타일에 `···`가 표시되며 클릭 시 상세 화면으로 이동합니다.
- 보안 인스턴스는 방패 아이콘으로 표시됩니다.
- 타일은 상태 순(에러 → 주의 → 실행 중 → 정지)으로 배치되며, 상태가 같은 인스턴스는 생성 순서로 표시됩니다. 자동 갱신이 일어나도 상태가 바뀌지 않은 인스턴스의 타일 위치는 유지됩니다.

## 자동 갱신

### 요약 정보

- 기본 자동 갱신 주기는 5초입니다.
- 자동 갱신 주기는 **꺼짐, 5초, 10초, 30초, 1분, 5분, 15분, 30분, 1시간** 중에서 선택할 수 있습니다.
- 새로고침 버튼 클릭 시 즉시 최신 데이터를 다시 조회합니다.
- 마지막 갱신 시각을 함께 제공합니다.
