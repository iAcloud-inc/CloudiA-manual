# ISO

`ISO`는 관리자 영역에서 가상머신 설치에 사용할 ISO 이미지를 업로드하고 관리하는 화면입니다. 업로드된 ISO는 프로젝트에서 ISO 설치 유형 인스턴스를 만들 때 사용할 수 있습니다.

## 화면 개요
- `목록 화면`: ISO 현황을 조회하고 업로드, 삭제 작업을 시작합니다.
- `업로드 화면`: `스토리지 도메인`, `ISO`, `OS 타입`을 지정해 새 ISO를 업로드합니다. `ISO`에서 파일을 고르면 `OS 타입`이 자동으로 채워집니다.

## ISO 목록
### 주요 작업
- `업로드`: 새로운 ISO를 업로드합니다.
- `삭제`: 선택한 ISO를 삭제합니다.

> 💡 **참고:** 목록은 단일 선택으로 동작하며, 항목 선택 시 `삭제` 버튼이 활성화됩니다.

### 검색
- **검색 조건**: `이름`
- **검색어 입력**: 검색어를 입력합니다.
- **검색 버튼**: 조건에 맞는 ISO를 조회합니다.

### 테이블 컬럼
| 컬럼 | 설명 |
| --- | --- |
| **이름** | ISO 이름입니다.<br>업로드한 ISO 파일 이름에서 확장자가 제거된 값입니다(예: `rocky-iso.iso` → `rocky-iso`). |
| **ID** | ISO 고유 ID입니다. |
| **OS 타입** | ISO에 지정된 OS 타입입니다.<br>`Rocky Linux 9`, `Windows Server 2022`처럼 제품명으로 표시되며, OS 타입을 판별할 수 없는 ISO는 `알 수 없음`으로 표시됩니다. |
| **크기** | ISO 파일 크기입니다. |
| **스토리지 도메인** | ISO가 저장된 스토리지 도메인입니다. |
| **생성 일시** | ISO를 등록한 일시입니다. |

## ISO 업로드
### 기본 정보
- **스토리지 도메인**: ISO를 저장할 스토리지 도메인을 선택합니다.
- **ISO**: 업로드할 `.iso` 파일을 선택합니다.
- **OS 타입**: `ISO`에서 파일을 고르면 자동으로 채워집니다. 채워지지 않으면 목록에서 직접 선택합니다.

### 입력 필드 유효성
| 필드 | 허용 값 | 검증 규칙 | 비고 |
| --- | --- | --- | --- |
| **스토리지 도메인** | 선택 가능한 스토리지 도메인 | 필수입니다. 1개를 선택합니다. | `CEPH`는 지원하지 않습니다. |
| **ISO** | `.iso` 파일 | 필수입니다. 파일을 선택해야 합니다. 광학 매체 형식(`ISO 9660` 또는 `UDF`)이어야 합니다. | 업로드 대상입니다. 부팅 가능 여부는 검사하지 않습니다. |
| **OS 타입** | 시스템 제공 OS 타입 | 필수입니다. 1개를 선택합니다. | `ISO`에서 파일을 고르면 자동으로 채워집니다. 채워진 값은 직접 바꿀 수 있습니다. |

> ⚠️ **주의:** ISO 업로드 시 `CEPH` 타입 스토리지 도메인은 선택할 수 없습니다.

### 업로드 시 참고 사항
- 모든 필수 항목을 입력하면 `업로드` 버튼이 활성화됩니다.
- `ISO`에서 파일을 고르면 `OS 타입`이 자동으로 채워집니다. 파일 전체를 업로드하기 전에 채워지므로 크기가 큰 설치 미디어도 바로 확인할 수 있습니다.
- 자동으로 채워지는 값은 메이저 버전 단위입니다. 예를 들어 `Rocky-9.5-x86_64-dvd.iso`는 `Rocky Linux 9`로 채워집니다.
- 다음 ISO는 `OS 타입`이 채워지지 않습니다. 이때는 목록에서 직접 선택합니다.
  - Windows Server 설치 미디어. `Windows Server 2016`부터 `2025`까지는 ISO에 담긴 식별 정보가 같아 한 가지로 특정할 수 없습니다.
  - 부팅할 수 없는 데이터 ISO, `virtio-win` 같은 드라이버 CD
  - 목록에 없는 배포판(`Fedora`, `openSUSE` 등)
- 자동으로 채워진 `OS 타입`도 직접 바꿀 수 있습니다. 파일을 다시 고르면 `OS 타입`은 비워지고 새 파일을 기준으로 다시 채워집니다.
- 업로드된 ISO는 프로젝트 인스턴스 생성 화면에서 ISO 설치 유형에 사용할 수 있습니다.
- 부팅할 수 없는 데이터 ISO도 업로드할 수 있습니다. 이런 ISO는 OS 설치용으로는 쓸 수 없지만, 인스턴스 생성 화면과 상세 화면의 `디스크 및 CD/DVD`에서 CD/DVD 드라이브로 연결할 수 있습니다.
- 광학 매체 형식이 아닌 파일(확장자만 `.iso`인 경우 등)은 업로드가 거부됩니다.

> ⚠️ **주의:** `OS 타입`은 이 ISO로 인스턴스를 만들 때 부팅 디스크의 기본 크기와 최소 크기를 정합니다. `Windows 10`·`Windows 11`과 `Windows Server 2019` 이상을 선택하면 `UEFI`와 `Secure Boot`가 기본 적용되고, 인스턴스 생성 화면의 `사용자 계정`과 `사용자 스크립트` 입력이 비활성화됩니다. `Windows Server 2016` 이하는 `BIOS`로 부팅합니다. 실제 ISO와 다른 `OS 타입`을 선택하면 인스턴스가 정상 부팅하지 않을 수 있습니다.

> 💡 **참고:** Windows 게스트에는 virtio 드라이버 CD가 자동으로 연결됩니다. 단 같은 스토리지 도메인에 드라이버 ISO가 등록되어 있어야 합니다.


## ISO 삭제
1. 목록에서 삭제할 ISO를 선택합니다.
2. `삭제`를 클릭합니다.
3. 삭제 확인 창에서 내용을 확인한 뒤 삭제를 진행합니다.

> ⚠️ **주의:** 연결된 인스턴스가 없는 ISO만 삭제할 수 있습니다.
