# 쿠버네티스

관리자 `쿠버네티스` 메뉴는 쿠버네티스 서비스(CKS)의 공통 기반 자원을 관리하는 영역입니다.

## 구성 메뉴
- **레지스트리**: 이 환경의 모든 CKS 클러스터가 컨테이너 이미지를 받아 가는 **관리 쿠버네티스 레지스트리**를 생성·삭제하고 전원을 제어합니다.

## 권장 작업 순서
1. 플랫폼 설치 후 `레지스트리` 화면에서 레지스트리가 존재하고 상태가 `실행 중`인지 확인합니다.
2. 레지스트리가 없으면 `생성`으로 만든 뒤 상태와 **레지스트리 VM 상태**가 정상이 될 때까지 기다립니다.
3. 이후 프로젝트 사용자가 클러스터를 생성합니다.

## 참고 사항
- 레지스트리는 관리형 VPC 안의 **VM**으로 동작하며, 환경당 1대만 존재합니다.
- 레지스트리가 없거나 정지되어 있으면 클러스터 생성과 노드 추가가 실패할 수 있습니다.
