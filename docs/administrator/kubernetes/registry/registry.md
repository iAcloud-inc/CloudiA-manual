# 레지스트리

`레지스트리`는 관리자 영역에서 **관리 쿠버네티스 레지스트리**를 관리하는 화면입니다. 이 레지스트리는 환경 안의 모든 쿠버네티스 클러스터가 컨테이너 이미지를 받아 가는 내부 레지스트리이며, 관리형 VPC 안의 **VM**으로 동작합니다.

환경당 **1대만** 존재하므로 목록 없이 단일 상세 화면으로 제공됩니다.

## 화면 개요
- `상세 화면`: 레지스트리의 존재 여부와 상태, VM 정보를 확인하고 생성·삭제·실행·종료 작업을 수행합니다.

## 주요 작업
- `생성`: 레지스트리를 생성합니다. 삭제된(`DELETED`) 레지스트리를 다시 활성화할 때도 사용합니다.
- `삭제`: 레지스트리를 삭제합니다. VM 은 반납되고 메타데이터만 남습니다.
- `실행`: 정지된(`DOWN`) 레지스트리를 다시 실행합니다.
- `종료`: 실행 중(`RUNNING`)인 레지스트리를 정지합니다.

> 💡 **참고:** 네 개 버튼은 항상 표시되며, 현재 상태에 따라 활성 여부만 바뀝니다. 생성·수정·삭제가 진행 중이면 모든 버튼이 비활성화됩니다.

## 상세 정보
| 항목 | 설명 |
| --- | --- |
| **이름** | 레지스트리 VM 이름입니다. |
| **상태** | 레지스트리 상태입니다. 예: `실행 중`, `정지됨`, `처리 중`, `종료 중`, `부팅 중`, `삭제됨`, `에러` |
| **레지스트리 VM 상태** | 헬스 점검 결과입니다. `정상`, `이상`, `알 수 없음` 중 하나입니다. 전원이 꺼져 있으면 `알 수 없음`으로 표시됩니다. |
| **IP** | 레지스트리 VM 의 IP 주소입니다. |
| **DNS** | 클러스터 노드가 사용하는 레지스트리 DNS 이름입니다. |
| **점검 일시** | 마지막 헬스 점검 일시입니다. |

> 💡 **참고:** 레지스트리가 아직 생성되지 않았으면 상세 정보 대신 데이터 없음이 표시되고 `생성` 버튼만 활성화됩니다.

## 상태 값
| 상태 | 설명 |
| --- | --- |
| `CREATING` | 생성 중입니다. 화면에는 `처리 중`으로 표시됩니다. |
| `UPDATING` | 변경 중입니다. 화면에는 `처리 중`으로 표시됩니다. |
| `DELETING` | 삭제 중입니다. 화면에는 `처리 중`으로 표시됩니다. |
| `RUNNING` | `실행 중`입니다. `종료`·`삭제`가 가능합니다. |
| `DOWN` | `정지됨` 상태입니다. `실행`·`삭제`가 가능합니다. |
| `POWERING_UP` | `부팅 중`입니다. |
| `STOPPING` | `종료 중`입니다. |
| `DELETED` | `삭제됨` 상태입니다. 메타데이터만 남아 있으며 `생성`으로 재활성할 수 있습니다. |
| `ERROR` | `에러` 상태입니다. |

## 레지스트리 생성
1. `생성`을 클릭합니다.
2. 상태가 `처리 중`(생성 중)으로 바뀌고, 화면이 자동으로 갱신됩니다.
3. 상태가 `실행 중`, **레지스트리 VM 상태**가 `정상`이 되면 완료입니다.

> 💡 **참고:** 생성에는 VM 프로비저닝 시간이 필요해 수 분이 걸립니다. 완료 전까지는 상세 정보가 표시되지 않을 수 있습니다.

> 💡 **참고:** 삭제된 레지스트리도 같은 `생성` 버튼으로 다시 활성화합니다.

## 레지스트리 실행 / 종료
1. `실행` 또는 `종료`를 클릭합니다.
2. 확인 창에서 이름, ID, DNS, IP, 점검 일시를 확인합니다.
3. 확인하면 상태가 `부팅 중`(시작 중) 또는 `종료 중`으로 바뀌고, 완료되면 `실행 중`·`정지됨`으로 전환됩니다.

> ⚠️ **주의:** 레지스트리를 정지하면 정지 중 쿠버네티스 클러스터가 이미지를 받지 못할 수 있습니다.

## 레지스트리 삭제
1. `삭제`를 클릭합니다.
2. 경고 내용을 확인합니다.
3. 확인 입력란에 **레지스트리 이름을 정확히 입력**합니다.
4. `삭제`를 클릭합니다.

> ⚠️ **주의:** 레지스트리를 삭제하면 VM 이 반납되고, 이 환경의 모든 쿠버네티스 클러스터가 이미지를 받지 못합니다. 메타데이터는 유지되므로 `생성`으로 재활성할 수 있습니다.

> ⚠️ **주의:** 이름을 정확히 입력해야 `삭제` 버튼이 활성화됩니다.

## 참고 사항
- 클러스터 생성과 노드 추가는 이 레지스트리에 의존합니다. 클러스터 생성이 반복 실패하면 먼저 이 화면에서 레지스트리 상태를 확인하세요.
- 사용자가 별도로 운영하는 사설 레지스트리를 클러스터에서 사용하려면, 프로젝트 화면의 [레지스트리 신뢰](../../../project/kubernetes/cluster/cluster.md#레지스트리-신뢰)에 CA 를 등록합니다.
