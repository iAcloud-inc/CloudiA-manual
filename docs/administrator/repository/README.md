# 저장소

관리자 `저장소` 메뉴는 플랫폼이 관리 VPC 안에 두는 내부 저장소 VM 을 관리하는 영역입니다. 두 저장소 모두 환경당 1대만
존재하므로 목록 없이 단일 상세 화면으로 제공됩니다.

## 구성 메뉴
- **레지스트리**: 이 환경의 모든 CKS 클러스터가 컨테이너 이미지를 받아 가는 **관리 쿠버네티스 레지스트리**를 생성·삭제하고 전원을 제어합니다.
- **패키지 저장소**: 인스턴스가 시작될 때 qemu-guest-agent 와 NFS 클라이언트를 내려받는 **패키지 미러**를 생성·삭제하고 전원을 제어하며, 미러에 든 패키지를 확인합니다.

## 권장 작업 순서
1. 플랫폼 설치 후 `레지스트리`와 `패키지 저장소` 화면에서 각 저장소가 존재하고 상태가 `실행 중`인지 확인합니다.
2. 저장소가 없으면 `생성`으로 만든 뒤 상태와 상태 검사 결과가 정상이 될 때까지 기다립니다.
3. 이후 프로젝트 사용자가 클러스터와 인스턴스를 생성합니다.

## 참고 사항
- 레지스트리가 없거나 정지되어 있으면 클러스터 생성과 노드 추가가 실패할 수 있습니다.
- 패키지 저장소가 없거나 정상이 아니면 새로 시작하는 인스턴스는 패키지 설치를 건너뜁니다. 인스턴스 시작 자체는 막지 않습니다.
- 이전 버전의 `쿠버네티스 > 레지스트리` 주소로 들어오면 `저장소 > 레지스트리`로 이동합니다.
