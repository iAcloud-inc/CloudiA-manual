# Cloud:iA CLI (cloudiactl)

`cloudiactl` 은 Cloud:iA 를 터미널에서 다루는 명령줄 도구입니다. 웹 콘솔에서 하던 일을 명령으로 실행하고, 결과를 JSON 으로 받아 스크립트나 AI 에이전트에서 이어서 쓸 수 있습니다.

## 할 수 있는 일

- 인스턴스·이미지·SSH 키·인스턴스 스냅샷 관리
- VPC·서브넷·보안그룹·플로팅 IP·내부 DNS·포트 포워딩 관리
- 블록·블록 스냅샷·파일 시스템·오브젝트 스토리지·ISO 관리
- L4·L7 로드 밸런서와 대상 그룹 관리
- 쿠버네티스 클러스터·노드 풀·GPU Operator 관리, kubeconfig 받기
- 비동기 요청 상태 확인, 조회 API 직접 호출

명령 목록은 접속한 Cloud:iA 의 API 에 맞춰 만들어집니다. 그 환경에 없는 기능은 명령에도 나타나지 않습니다.

## 알아 둘 점

- 지금은 미리보기 버전입니다. 명령 이름과 출력 형식이 바뀔 수 있습니다.
- 메시지는 영어로만 나옵니다. 주 사용자인 AI 에이전트가 안정된 문구와 오류 코드로 판단하게 하려는 것입니다.
- 로그인은 웹 콘솔에서 승인하는 방식만 정식으로 지원합니다. CI 같은 무인 실행은 아직 정식으로 지원하지 않습니다. 자세한 내용은 [로그인](./login.md)의 '무인 실행(CI)' 절을 참고하세요.
