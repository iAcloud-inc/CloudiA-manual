# 클러스터

## 화면 개요

**클러스터**는 쿠버네티스 컨트롤 플레인, 워커 노드, 네트워크, 스토리지, 리소스를 통합 관리하는 기능입니다.

## 클러스터 목록
클러스터 목록을 확인합니다.

### 주요 작업
- `생성`: 새 클러스터를 생성합니다.
- `삭제`: 선택한 클러스터를 삭제합니다.

> 💡 **공통 조건:** 목록에서 좌측 **라디오 버튼**으로 클러스터를 선택합니다. 한 번에 **1개 클러스터만 선택**할 수 있습니다.

### 테이블 컬럼
| 컬럼 | 설명 |
|------|------|
| **이름** | 클러스터 이름입니다. 클릭하면 상세 화면으로 이동합니다. |
| **ID** | 클러스터의 고유 ID입니다. |
| **버전** | 클러스터의 쿠버네티스 버전입니다. |
| **API 서버 엔드포인트 IP** | API 서버 접근에 사용하는 엔드포인트 IP 주소입니다. |
| **상태** | 예: `ERROR`, `WARNING`, `UNKNOWN`, `DOWN`, `UP`, `POWERING_UP`, `STOPPING`, `CREATING`, `DELETING`, `DELETE_FAILED`, `DELETED`, `CA_ROTATING`, `PENDING` |
| **컨트롤 플레인** | 정상 상태의 컨트롤 플레인 수/전체 수를 `N/N` 형식으로 표시합니다. |
| **워커 노드** | 정상 상태의 워커 노드 수/전체 수를 `N/N` 형식으로 표시합니다. |
| **생성 일시** | 생성 일시를 표시합니다. |

> ⚠️ **주의:** `삭제 중(DELETING)` 상태의 클러스터는 삭제할 수 없습니다.

## 클러스터 상세
선택한 클러스터의 기본 정보와 하위 섹션을 확인합니다.

### 상단 요약
- **이름**: 클러스터 이름입니다.
- **ID**: 클러스터의 고유 ID입니다.
- **버전**: 쿠버네티스 버전입니다.
- **VPC**: `VPC 이름 (ID: VPC ID)` 형식으로 표시됩니다.
- **API 서버 엔드포인트 IP**: API 서버 접근에 사용하는 엔드포인트 IP 주소입니다.
- **상태**: 클러스터 상태입니다.
- **생성 일시**: 생성 일시입니다.

### 주요 작업
- `인증서 재설정`: 새 `ca.crt` 와 `ca.key` 를 업로드해 CA를 재설정합니다.

#### 인증서 재설정
- `ca.crt`, `ca.key` 를 모두 선택해야 저장할 수 있습니다.
- 재설정 중에는 상태가 `CA_ROTATING`으로 표시되며, 완료되면 다시 `UP`으로 복귀합니다.

> ⚠️ **주의:** 인증서 재설정은 클러스터 상태가 `UP`, `WARNING`, `CA_ROTATING` 일 때만 진행할 수 있습니다.

### 하단 섹션
상세 화면 하단에서는 **클러스터 구성 요소**, **AI 가속기**, **쿠버네티스 리소스**, **스토리지**, **접근 관리**, **이벤트** 섹션을 좌측 사이드네비로 전환해 확인할 수 있으며, 그 아래 **모니터링 정보** 섹션이 이어집니다. 기본 정보 아래에는 **네트워크 정보** 박스가 함께 표시됩니다.

- **클러스터 구성 요소**: `노드`, `워커 오토 스케일링 그룹`, `서비스 로드 밸런서`
- **AI 가속기**: 가속기(GPU/NPU) 사용량
- **쿠버네티스 리소스**: `시스템 파드`, `디플로이먼트`, `데몬셋`, `서비스`
- **스토리지**: `스토리지 클래스`, `PVC`
- **접근 관리**: RBAC
- **이벤트**: 클러스터 이벤트
- **모니터링 정보**: 클러스터 상태와 사용량
- **네트워크 정보**: 서브넷, 보안그룹, API 서버 로드 밸런서

> ⚠️ **주의:** 클러스터 상태가 `UP`·`WARNING`·`CA_ROTATING`(실시간 가용 상태)가 아니면 `AI 가속기`·`쿠버네티스 리소스`·`스토리지`·`접근 관리`·`이벤트` 섹션 대신 "현재 클러스터 상태에서는 실시간 정보를 표시할 수 없습니다." 안내가 표시됩니다. `노드`(클러스터 구성 요소)·`네트워크 정보`는 이 안내와 무관하게 표시됩니다.

#### 모니터링 정보
클러스터 상태와 사용량을 모니터링합니다.

##### 주요 작업
- `새로고침`: 최신 데이터를 다시 조회합니다.
- `자동 새로고침`: 일정 주기로 데이터를 자동 갱신합니다.

##### 주요 표시 영역
- **컨트롤 플레인 평균 부하**: CPU, Memory, Disk 사용률
- **파드 상태**: `Running`, `Pending`, `Succeed`, `Failed`, `Unknown`
- **워커 노드 사용량**: CPU, Memory, `Network rx`, `Network tx`
- **노드 상태**: 컨트롤 플레인/워커의 정상 수와 전체 수

> 💡 **참고:** CPU 사용 제한이나 메모리 부족 위험이 감지되면 경고 문구가 함께 표시될 수 있습니다.

#### 노드
컨트롤 플레인과 워커 노드 목록을 확인하고, 워커 노드 관련 작업을 수행합니다.

##### 주요 작업
- `워커 노드 추가`: 새 워커 노드를 추가합니다.
- `워커 노드 삭제`: 선택한 워커 노드를 삭제합니다.

##### 테이블 컬럼
| 컬럼 | 설명 |
|------|------|
| **역할** | `컨트롤 플레인` 또는 `워커 노드`입니다. |
| **노드 이름** | 클릭 시 VM 인스턴스 상세로 이동합니다. |
| **ID** | 노드의 고유 ID입니다. |
| **버전** | 쿠버네티스 버전입니다. |
| **기본 인터페이스 IP 주소** | 노드 IP 주소입니다. |
| **인스턴스 타입** | 연결된 인스턴스 타입입니다. |
| **상태** | 예: `ERROR`, `DOWN`, `UP`, `POWERING_UP`, `CREATING`, `DELETING`, `DELETED`, `PENDING`, `CA_ROTATING`, `READY`, `NOT_READY`, `UNKNOWN`, `MACHINE_DOWN`, `ORPHANED` |
| **생성 일시** | 생성 일시입니다. |

> ⚠️ **주의:** 컨트롤 플레인 노드는 삭제할 수 없습니다.

> ⚠️ **주의:** `PENDING`, `CREATING`, `DELETING` 상태의 워커 노드는 삭제할 수 없습니다.

> ⚠️ **주의:** 생성 중이거나 삭제 중인 노드는 상세 화면으로 이동할 수 없습니다.

#### 워커 오토 스케일링 그룹
워커 오토 스케일링 그룹 목록을 확인하고 관리합니다.

##### 주요 작업
- `생성`: 워커 오토 스케일링 그룹을 생성합니다.
- `삭제`: 목록에서 선택한 그룹을 삭제합니다.

##### 테이블 컬럼
| 컬럼 | 설명 |
|------|------|
| **이름** | 그룹 이름입니다. 클릭하면 상세 화면으로 이동합니다. |
| **ID** | 그룹의 고유 ID입니다. |
| **인스턴스 상태** | `정상 수/전체 수개` 형식으로 표시합니다(예: `3/5개`). |
| **상태** | 예: `UP`, `CREATING`, `DELETING`, `SCALING_OUT`, `SCALING_IN` |
| **생성 일시** | 생성 일시입니다. |

#### 스토리지
스토리지 클래스와 PVC를 좌측 사이드네비로 전환해 조회하고 생성합니다.

##### 주요 작업
- `스토리지 클래스 생성`
- `PVC 생성`

##### 스토리지 클래스 목록 컬럼

| **서버** | `parameters.server` 값입니다. |

| **프로비저너** | `provisioner` 값입니다. |
| **반환 정책** | `Delete` 또는 `Retain`입니다. |
| **볼륨 바인딩 모드** | `volumeBindingMode` 값입니다. |
| **기본** | 기본 스토리지 클래스 여부입니다. |

| **설정 용량** | 요청한 용량입니다. |

> 💡 **참고:** 스토리지 섹션에서는 스토리지 클래스와 PVC를 조회하고 생성할 수 있습니다.

#### 쿠버네티스 리소스
시스템 파드, 디플로이먼트, 데몬셋, 서비스를 좌측 사이드네비로 전환해 조회합니다.

##### 표시 항목
- **시스템 파드**: 이름, 준비 상태(`Ready`), 상태, 재시작 횟수, 경과 시간, 파드 IP, 노드 이름
- **디플로이먼트**: 이름, 네임스페이스, Replicas(`readyReplicas/replicas`), 경과 시간, Ready, 상태, Strategy
- **서비스**: 이름, 네임스페이스, Type, Cluster IP, External IP, Ports, 경과 시간, 상태
- **데몬셋**: 이름, 네임스페이스, Desired Nodes, Available Nodes, 경과 시간, Ready Pods, 상태, Update Strategy

> ⚠️ **주의:** 쿠버네티스 리소스 섹션은 조회 전용입니다.

#### 이벤트
클러스터 이벤트 목록을 별도 섹션으로 제공합니다.

- **표시 항목**: 경과 시간, Type, 네임스페이스, Reason, Message

> ⚠️ **주의:** 이벤트 섹션은 조회 전용입니다.

## 클러스터 생성
클러스터를 생성할 때 기본 정보, 네트워크, 컨트롤 플레인, 사용자 계정, CA 파일을 입력합니다.

> 💡 **참고:** 필수 항목을 모두 입력하면 **생성** 버튼이 활성화됩니다.

### 기본 정보
- **클러스터 이름**을 입력합니다.

#### 입력 필드 유효성
| 필드 | 허용 값 | 검증 규칙 | 비고 |
|------|------|------|------|
| **클러스터 이름** | 소문자, 숫자, `-` | 최대 `40자`, 첫 글자 숫자 불가 | **필수** |

### VPC 및 서브넷 설정
- **VPC**를 먼저 선택합니다.
- 선택한 VPC에 맞는 **서브넷**을 선택합니다.
- 필요한 경우 **추가 보안그룹**을 선택합니다.

> 💡 **참고:** 기본 보안그룹은 클러스터 생성 과정에서 자동으로 준비됩니다.

> ⚠️ **주의:** 추가 보안그룹은 최대 `4개`까지 선택할 수 있습니다.

### 컨트롤 플레인 설정
- **인스턴스 구성**을 선택합니다.
- **버전**을 선택합니다.
- **컨트롤 플레인 수**를 선택합니다.

#### 고급 옵션
버전을 선택하면 **고급 옵션**을 펼칠 수 있습니다. 고급 옵션에서는 다음 항목을 설정합니다.

- **디스크 크기 설정**을 입력합니다.
- **스토리지 도메인**을 선택합니다. (선택)

> 💡 **참고:** 컨트롤 플레인 수는 `1` 또는 `3` 중에서 선택합니다.

> 💡 **참고:** 고급 옵션은 **버전을 먼저 선택**해야 펼칠 수 있습니다.

> 💡 **참고:** 스토리지 도메인을 선택하면 해당 도메인에 인스턴스가 배치됩니다. 선택하지 않으면 시스템이 자동으로 배치합니다.

> ⚠️ **주의:** 디스크 크기 설정은 최소 `32 GB` 이상 입력합니다.

### 사용자 계정 및 인증 방식
- **사용자 이름**을 입력합니다.
- 인증 방식은 비밀번호 또는 SSH 키를 사용할 수 있습니다.
- 비밀번호를 사용하는 경우 비밀번호와 확인 값을 모두 입력합니다.

### CA 파일 설정
- **CA 인증서(`ca.crt`)**
- **개인 키(`ca.key`)**

`선택` 버튼을 클릭해 열릴 모달에서 파일을 첨부하고, 모달의 `추가` 버튼으로 확인합니다. 두 파일을 모두 선택하거나, 모두 선택하지 않을 수 있습니다. CA 파일을 첨부하지 않으면 시스템이 자동으로 CA를 생성합니다.

> ⚠️ **주의:** CA 인증서와 개인 키 중 하나만 첨부할 수 없습니다. 둘 다 첨부하거나 둘 다 첨부하지 않아야 합니다.

#### CA 파일 직접 생성 예시
CA 파일을 직접 준비하려면 `openssl`로 개인 키와 자체 서명 인증서를 생성할 수 있습니다.

```bash
# 개인 키(ca.key) 생성
openssl genrsa -out ca.key 4096

# 자체 서명 CA 인증서(ca.crt) 생성 (유효기간 10년)
openssl req -x509 -new -nodes -key ca.key -days 3650 -subj "/CN=kubernetes-ca" -out ca.crt
```

> 💡 **참고:** 생성된 `ca.key`(개인 키)와 `ca.crt`(CA 인증서)를 CA 파일 설정에서 각각 첨부합니다.

#### 입력 필드 유효성
| 필드 | 허용 값 | 검증 규칙 | 비고 |
|------|------|------|------|
| **VPC** | 프로젝트 내 VPC 1개 | 선택 필요 | **필수** |
| **서브넷** | 선택 가능한 서브넷 1개 | 선택 필요 | **필수** |
| **추가 보안그룹** | 선택 가능한 보안그룹 | 최대 `4개` 선택 가능 | 선택 |
| **인스턴스 구성** | 인스턴스 타입 또는 직접 입력 | 유효한 값 선택 필요 | **필수** |
| **버전** | 사용 가능한 쿠버네티스 버전 | 선택 필요 | **필수** |
| **컨트롤 플레인 수** | `1` 또는 `3` | 값 중 하나를 선택해야 함 | **필수** |
| **디스크 크기 설정** | 정수 | 최소 `32 GB` 이상 | **필수** (고급 옵션) |
| **스토리지 도메인** | 사용 가능한 스토리지 도메인 | 선택 가능 | 선택 (고급 옵션) |
| **CA 인증서/개인 키** | 파일 업로드 | 둘 다 첨부하거나 둘 다 미첨부 | 선택 |
| **사용자 계정/인증 방식** | 사용자명 + 비밀번호 또는 SSH 키 | 유효성 검사 통과 필요 | **필수** |

### 생성 결과
- 생성 요청 직후 목록에 새 클러스터가 `CREATING` 상태로 표시됩니다.
- 완료되면 `UP` 상태로 전환됩니다.
- 클러스터 생성과 함께 컨트롤 플레인 노드, 로드밸런서, 타겟 그룹이 자동으로 준비됩니다.

> ⚠️ **주의:** 프로젝트 자원이나 서브넷의 사용 가능 IP가 부족하면 생성이 실패할 수 있습니다.
