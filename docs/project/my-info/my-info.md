# 내 정보

## 화면 개요

**내 정보** 화면에서는 로그인한 본인의 계정 정보를 확인하고, 휴대폰 번호와 비밀번호를 직접 관리합니다. 화면 우측 상단의 계정 메뉴에서 진입하며, 관리자 멤버와 프로젝트 멤버 모두 사용할 수 있습니다.

다른 사용자의 계정을 관리하는 화면은 관리자 매뉴얼의 [멤버](../../administrator/access-management/member/member.md)를 참고하세요.

## 내 정보 확인

로그인한 본인의 프로필 정보를 한눈에 확인합니다.

### 표시 항목
| 항목 | 설명 |
|---|---|
| 이름 | 로그인 계정의 이름입니다. |
| 휴대폰 | 등록된 휴대폰 번호입니다. |
| 이메일 | 계정 이메일 주소입니다. |
| 타입 | `관리자 멤버`인지 `프로젝트 멤버`인지 표시합니다. |
| 역할 | 관리자 멤버는 현재 **관리자 역할**을 표시합니다. 프로젝트 멤버는 화면 하단에서 **프로젝트별 역할** 목록을 확인할 수 있습니다. |

### 주요 작업
- `편집`: 내 프로필을 수정하는 화면으로 이동합니다.
- `비밀번호 변경`: 본인 계정의 비밀번호를 변경합니다.

## 내 정보 편집

`편집`을 누르면 프로필 편집 화면으로 이동합니다.

### 입력 항목
- **휴대폰** 번호만 수정할 수 있습니다.
- **이름**과 **이메일**은 조회 전용으로, 이 화면에서는 변경할 수 없습니다. (이름·이메일 변경이 필요하면 관리자에게 문의하세요.)

### 입력 규칙
- 휴대폰 번호: 10자리 또는 11자리 숫자로 입력합니다.

### 절차
1. `편집`을 클릭합니다.
2. **휴대폰** 번호를 수정합니다.
3. `저장`을 눌러 변경 내용을 적용합니다.

> 💡 **참고:** 기존 값에서 바뀐 내용이 있고 입력값이 올바를 때만 `저장` 버튼이 활성화됩니다.

## 비밀번호 변경

`비밀번호 변경`을 누르면 비밀번호 변경 창이 열립니다.

### 입력 항목
- **현재 비밀번호**: 본인 확인을 위해 지금 사용 중인 비밀번호를 입력합니다.
- **새 비밀번호**: 변경할 비밀번호를 입력합니다.
- **새 비밀번호 확인**: 새 비밀번호와 동일하게 한 번 더 입력합니다.

### 절차
1. `비밀번호 변경`을 클릭합니다.
2. **현재 비밀번호**를 입력합니다.
3. **새 비밀번호**와 **새 비밀번호 확인**을 입력합니다.
4. `저장`을 눌러 변경합니다.

> 💡 **참고:** 새 비밀번호는 현재 적용된 비밀번호 정책을 만족해야 합니다. 정책은 관리자 매뉴얼의 [정책 설정](../../administrator/setting/policy-setting/policy-setting.md)에서 확인할 수 있습니다.

## 사용 시 참고
- 이 화면은 **본인 계정**만 대상으로 합니다. 다른 사용자의 정보 조회·수정은 관리자 권한이 있는 경우 [멤버](../../administrator/access-management/member/member.md) 화면에서 수행합니다.
