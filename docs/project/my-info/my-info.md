# 내 정보

## 화면 개요

**내 정보** 화면에서는 로그인한 본인의 계정 정보를 확인하고, 휴대폰 번호와 비밀번호를 직접 관리합니다. 화면 우측 상단의 계정 메뉴에서 진입하며, 관리자 멤버와 프로젝트 멤버 모두 사용할 수 있습니다.

지금 쓰는 CloudiA 의 버전은 같은 계정 메뉴의 `버전 정보`에서 봅니다. [버전 정보](#버전-정보)를 참고하세요.

다른 사용자의 계정을 관리하는 화면은 관리자 매뉴얼의 [멤버](../../administrator/access-management/member/member.md)를 참고하세요.

## 내 정보 확인

로그인한 본인의 프로필 정보를 한눈에 확인합니다.

### 표시 항목
| 항목 | 설명 |
|---|---|
| 이름 | 로그인 계정의 이름입니다. |
| 휴대폰 번호 | 등록된 휴대폰 번호입니다. |
| 이메일 | 계정 이메일 주소입니다. |
| 타입 | `관리자 멤버`인지 `프로젝트 멤버`인지 표시합니다. |
| 관리자 역할 | 현재 부여된 관리자 역할입니다. **관리자 멤버에게만 표시됩니다.** 프로젝트 멤버에게는 이 항목이 나타나지 않고, 화면 하단에서 **프로젝트별 역할** 목록을 확인합니다. |
| 연결된 외부 계정 | 내 계정에 이어진 외부 계정(예: `Microsoft (hong@example.com)`)입니다. 없으면 `-`로 보입니다. **SSO(외부 계정 로그인)를 켠 설치에서만 표시됩니다.** |

### 주요 작업
- `편집`: 내 프로필을 수정하는 화면으로 이동합니다.
- `비밀번호 변경`: 본인 계정의 비밀번호를 변경합니다.
- `연동 해제`: 연결된 외부 계정 옆에 있습니다. 확인하면 그 외부 계정 연결만 끊기고, 계정과 권한, 지금 로그인된 화면은 그대로입니다. 외부 계정으로만 로그인하는 계정(CloudiA 비밀번호가 없는 계정)은 마지막 연결을 끊을 수 없습니다. 끊어야 한다면 관리자에게 비밀번호 설정을 요청하세요.

## 내 정보 편집

`편집`을 누르면 프로필 편집 화면으로 이동합니다.

### 입력 항목
- **휴대폰 번호**만 수정할 수 있습니다.
- **이름**과 **이메일**은 조회 전용으로, 이 화면에서는 변경할 수 없습니다. (이름·이메일 변경이 필요하면 관리자에게 문의하세요.)

### 입력 규칙
- 휴대폰 번호: 10자리 또는 11자리 숫자로 입력합니다.

### 절차
1. 화면 우측 상단의 `편집`을 클릭합니다.
2. **휴대폰 번호**를 수정합니다.
3. `편집` 버튼을 눌러 변경 내용을 적용합니다.

> 💡 **참고:** 기존 값에서 바뀐 내용이 있고 입력값이 올바를 때만 `편집` 버튼이 활성화됩니다.

## 비밀번호 변경

`비밀번호 변경`을 누르면 변경 창이 열리며, **사용자 인증 → 비밀번호 변경** 2단계로 진행합니다.

### 1단계: 사용자 인증
1. `비밀번호 변경`을 클릭합니다.
2. **현재 비밀번호**를 입력합니다.
3. `확인`을 눌러 본인 인증을 완료합니다.

### 2단계: 비밀번호 변경
1. **새 비밀번호**를 입력합니다.
2. **비밀번호 확인**에 새 비밀번호와 동일하게 다시 입력합니다.
3. `변경`을 눌러 비밀번호를 변경합니다.

> 💡 **참고:** 새 비밀번호는 현재 적용된 비밀번호 정책을 만족해야 합니다. 정책은 관리자 매뉴얼의 [정책 설정](../../administrator/setting/policy-setting/policy-setting.md)에서 확인할 수 있습니다.

## 버전 정보

화면 우측 상단의 계정 메뉴에서 `버전 정보`를 누르면, 지금 쓰고 있는 CloudiA 의 버전을 보여 주는 창이 열립니다. 관리자 멤버와 프로젝트 멤버 모두 사용할 수 있습니다.

### 표시 항목
| 항목 | 설명 |
|---|---|
| 제품 | 제품 이름과 제품 버전입니다. 예: `Cloud:iA v1.0` |
| 버전 | 설치된 판의 버전입니다. `<제품 버전>.<마이너 버전>-build<빌드 날짜>` 형식입니다. 예: `1.0.7-build20261105`. 버전 정보 기능이 들어간 판으로 설치하거나 업데이트한 적이 없는 설치본에는 버전 기록이 없어서 `-`로 보입니다. |

### 주요 작업
- `복사`: 버전 값을 클립보드에 복사합니다. 복사되면 `복사됨` 안내가 뜹니다.
- `확인`: 창을 닫습니다.

> 💡 **참고:**
> - 버전은 창을 열 때마다 새로 읽습니다. 업데이트가 끝난 뒤 창을 다시 열면 바뀐 버전이 보입니다.
> - 로그인 화면 아래쪽에는 제품 버전(예: `Cloud:iA v1.0`)만 표시됩니다. 빌드 날짜가 붙은 버전은 로그인한 뒤 이 창에서 확인합니다.
> - 버전을 불러오지 못하면 `버전 정보를 불러오지 못했습니다. 잠시 후 다시 시도해주세요.` 안내가 뜹니다. 잠시 뒤 창을 다시 열어 보세요.

## 사용 시 참고
- 이 화면은 **본인 계정**만 대상으로 합니다. 다른 사용자의 정보 조회·수정은 관리자 권한이 있는 경우 [멤버](../../administrator/access-management/member/member.md) 화면에서 수행합니다.
