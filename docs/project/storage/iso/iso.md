# ISO

`ISO`는 프로젝트에서 가상머신 설치에 쓸 ISO 이미지를 업로드하고 관리하는 화면입니다. 프로젝트가 올린 `프로젝트 ISO`와 관리자가 올린 `공용 ISO`를 함께 보여 줍니다. 업로드한 ISO는 인스턴스를 ISO 설치 유형으로 만들거나 CD/DVD 드라이브에 연결할 때 사용합니다.

## 화면 개요
- `목록 화면`: ISO 현황을 조회하고 업로드, 복제, 삭제 작업을 시작합니다.
- `업로드 화면`: `스토리지 도메인`, `ISO`, `OS 유형`을 지정해 새 ISO를 업로드합니다. `ISO`에서 파일을 고르면 `OS 유형`이 자동으로 채워집니다.
- `복제 창`: 선택한 ISO를 프로젝트에 배정된 다른 스토리지 도메인으로 복제합니다.

## ISO 목록
### 주요 작업
- `업로드`: 새 프로젝트 ISO를 업로드합니다.
- `복제`: 선택한 1개 ISO를 다른 파일 스토리지 도메인으로 복제합니다.
- `삭제`: 선택한 프로젝트 ISO를 삭제합니다.

> 💡 **참고:** 목록은 단일 선택으로 동작합니다. 복사 중이라 크기 칸이 `생성 중`인 ISO는 선택할 수 없습니다.

### 표시되는 ISO
- 이 프로젝트가 올린 `프로젝트 ISO`와 관리자가 올린 `공용 ISO`가 함께 나옵니다.
- 프로젝트에 배정된 스토리지 도메인에 있는 ISO만 보입니다. 다른 프로젝트가 올린 ISO는 보이지 않습니다.
- 관리자 영역의 **공용 ISO** 목록에는 프로젝트 ISO가 나오지 않습니다.

### 검색
- **검색 조건**: `이름`
- **검색어 입력**: 검색어를 입력합니다.
- **검색 버튼**: 조건에 맞는 ISO를 조회합니다.

### 테이블 컬럼
| 컬럼 | 설명 |
| --- | --- |
| **이름** | ISO 이름입니다.<br>업로드한 ISO 파일 이름에서 확장자를 뺀 값입니다(예: `rocky-iso.iso` → `rocky-iso`). |
| **ID** | ISO 고유 ID입니다. |
| **분류** | `프로젝트 ISO` 또는 `공용 ISO`입니다. |
| **OS 유형** | ISO에 지정한 OS 유형입니다.<br>`Rocky Linux 9`, `Windows Server 2022`처럼 제품명으로 표시되며, 판별할 수 없는 ISO는 `알 수 없음`으로 표시됩니다. |
| **크기** | ISO 파일 크기입니다. 복사 중이면 `생성 중`으로 표시됩니다. |
| **스토리지 도메인** | ISO가 저장된 스토리지 도메인입니다. |
| **생성 일시** | ISO를 등록한 일시입니다. |

## ISO 업로드
### 기본 정보
- **스토리지 도메인**: ISO를 저장할 스토리지 도메인을 선택합니다. 관리자가 이 프로젝트에 배정한 도메인만 나옵니다.
- **ISO**: 업로드할 `.iso` 파일을 선택합니다.
- **OS 유형**: `ISO`에서 파일을 고르면 자동으로 채워집니다. 채워지지 않으면 목록에서 직접 선택합니다.

### 입력 필드 유효성
| 필드 | 허용 값 | 검증 규칙 | 비고 |
| --- | --- | --- | --- |
| **스토리지 도메인** | 이 프로젝트에 배정된 스토리지 도메인 | 필수입니다. 1개를 선택합니다. | `CEPH`(RBD)는 지원하지 않습니다. Ceph 클러스터에 올리려면 `CEPHFS` 도메인을 선택합니다. |
| **ISO** | `.iso` 파일 | 필수입니다. 광학 매체 형식(`ISO 9660` 또는 `UDF`)이어야 합니다. | 부팅 가능 여부는 검사하지 않습니다. |
| **OS 유형** | 시스템 제공 OS 유형 | 필수입니다. 1개를 선택합니다. | 자동으로 채워진 값도 직접 바꿀 수 있습니다. |

### 업로드 시 참고 사항
- 모든 필수 항목을 입력하면 `업로드` 버튼이 활성화됩니다.
- `OS 유형`은 파일 전체를 올리기 전에 채워지며, 메이저 버전 단위입니다(예: `Rocky-9.5-x86_64-dvd.iso` → `Rocky Linux 9`). 채워지지 않는 ISO와 자동 판별 규칙은 [공용 ISO 업로드](../../../administrator/storage/iso/iso.md#iso-업로드)와 같습니다.
- 파일을 다시 고르면 `OS 유형`은 비워지고 새 파일을 기준으로 다시 채워집니다.
- 부팅할 수 없는 데이터 ISO도 업로드할 수 있습니다. 이런 ISO는 OS 설치에는 쓸 수 없지만 CD/DVD 드라이브로 연결할 수 있습니다.
- 광학 매체 형식이 아닌 파일(확장자만 `.iso`인 경우 등)은 업로드가 거부됩니다.

> ⚠️ **주의:** `OS 유형`은 이 ISO로 인스턴스를 만들 때 부팅 디스크의 기본 크기와 최소 크기, 부팅 방식을 정합니다. 실제 ISO와 다른 `OS 유형`을 선택하면 인스턴스가 정상 부팅하지 않을 수 있습니다. 자세한 내용은 [공용 ISO 업로드](../../../administrator/storage/iso/iso.md#iso-업로드)의 주의 사항을 참고하세요.

### 디스크 할당량
프로젝트 ISO는 저장한 스토리지 도메인의 디스크 할당량을 ISO 파일 크기만큼 사용합니다. `공용 ISO`는 프로젝트 할당량을 쓰지 않습니다.

- 할당량이 부족하면 `디스크 할당량이 부족합니다.` 알림이 표시되고 ISO가 등록되지 않습니다.
- 할당량 제한을 쓰지 않는 프로젝트는 할당량 때문에 거부되지 않습니다.

## ISO 활용
- **가상머신 > 인스턴스 생성**에서 ISO 설치 유형을 고르면 이 프로젝트에서 보이는 ISO 중에서 선택합니다.
- 인스턴스 생성 화면과 인스턴스 상세의 `디스크 및 CD/DVD`에서 ISO를 CD/DVD 드라이브로 연결할 수 있습니다.

## ISO 복제
LOCAL 도메인에 올린 ISO를 다른 호스트의 인스턴스에 붙여야 할 때처럼, 다시 올리지 않고 다른 스토리지 도메인으로 복제합니다.

1. 목록에서 복제할 ISO를 선택합니다.
2. `복제`를 클릭합니다.
3. 대상 스토리지 도메인을 선택합니다.

- 대상으로는 이 프로젝트에 배정된 도메인만 고를 수 있습니다.
- 사본은 원본과 같은 이름의 `프로젝트 ISO`가 됩니다.
- 복사가 끝날 때까지 사본의 크기 칸은 `생성 중`으로 보이고, 그동안은 삭제하거나 인스턴스에 연결할 수 없습니다.
- 사본도 대상 도메인의 디스크 할당량을 사용합니다. 할당량이 부족하면 `디스크 할당량이 부족합니다.` 알림과 함께 복제가 거부됩니다.

> ⚠️ **주의:** ISO는 파일 스토리지 도메인(NFS·GFS2·CephFS·로컬)에만 복제할 수 있습니다. 원본이 있는 도메인과 Ceph(RBD) 도메인은 고를 수 없습니다.

## ISO 삭제
1. 목록에서 삭제할 ISO를 선택합니다.
2. `삭제`를 클릭합니다.
3. 삭제 확인 창에서 내용을 확인한 뒤 삭제를 진행합니다.

- 이 프로젝트에서 올린 ISO이고 연결된 인스턴스가 없을 때만 삭제할 수 있습니다. 조건에 맞지 않으면 확인 창의 삭제 버튼이 비활성화되고 그 이유가 표시됩니다.
- 삭제하면 그 ISO가 쓰던 디스크 할당량을 바로 돌려받습니다.

> ⚠️ **주의:** `공용 ISO`는 프로젝트에서 삭제할 수 없습니다. 관리자가 프로젝트 ISO를 [공용 ISO로 가져오면](../../../administrator/storage/iso/iso.md#프로젝트-iso-가져오기) 원래 프로젝트에서도 `공용 ISO`로 보이고 더 이상 지울 수 없습니다.
