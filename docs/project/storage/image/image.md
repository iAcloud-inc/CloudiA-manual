# 이미지

`이미지`는 가상머신 생성에 필요한 운영체제(OS) 이미지를 업로드하고 관리할 수 있는 공간입니다.  
사용자는 프로젝트 내에서 이미지 목록을 확인하고, 새 이미지를 추가하거나 기존 이미지를 삭제할 수 있습니다.  
또한, 관리자가 추가한 이미지는 모든 프로젝트에서 공통적으로 사용할 수 있습니다.

## 화면 개요
- `목록 화면`: 이미지 현황을 조회하고 업로드, 복제, 삭제 작업을 시작합니다.
- `상세 화면`: 이미지의 기본 정보와 OS 정보, 게스트 기능(cloud-init·qemu-guest-agent) 설치 여부를 확인합니다.
- `업로드 화면`: 스토리지 도메인과 이미지 파일을 지정해 새 프로젝트 이미지를 등록합니다.
- `복제 모달`: 선택한 이미지를 다른 스토리지 도메인으로 복제합니다.

## 이미지 목록
### 주요 작업
- `업로드`: 새로운 프로젝트 이미지를 업로드합니다.
- `복제`: 선택한 1개 이미지를 다른 스토리지 도메인으로 복제합니다.
- `삭제`: 선택한 1개 이미지를 삭제합니다.

> 💡 **참고:** 목록은 단일 선택 방식으로 동작합니다.

### 검색
- **검색 조건**: `이름`
- **검색어 입력**: 검색어를 입력합니다.
- **검색 버튼**: 조건에 맞는 이미지를 조회합니다.

### 테이블 컬럼
| 컬럼 | 설명 |
| --- | --- |
| **이름** | 이미지 이름입니다. **클릭하면 상세 화면으로 이동합니다.**<br>업로드한 이미지 파일 이름에서 확장자가 제거된 값입니다(예: `rocky.qcow2` → `rocky`). |
| **ID** | 이미지 고유 ID입니다. |
| **분류** | 이미지 분류입니다.<br>`프로젝트 이미지`, `공용 이미지`로 구분됩니다. |
| **OS 타입** | 이미지의 OS 타입입니다.<br>`Rocky Linux 9`, `Windows Server 2022`처럼 제품명으로 표시되며, OS 타입을 판별할 수 없는 이미지는 `알 수 없음`으로 표시됩니다. |
| **부팅 펌웨어** | 업로드 시 선언한 부팅 펌웨어(`BIOS`/`UEFI`/`지정 안 함`)입니다. |
| **크기** | 이미지 파일 크기입니다.<br>업로드·변환이 진행 중인 이미지는 크기 대신 `생성 중`으로 표시되며, 변환이 완료되면 실제 크기로 자동 전환됩니다. |
| **스토리지 도메인** | 이미지가 저장된 스토리지 도메인입니다. |
| **생성 일시** | 이미지를 추가한 일시입니다. |

### 이미지 분류
이미지 분류는 프로젝트 이미지와 공용 이미지로 구성되어 있습니다.   
프로젝트 이미지는 사용자가 추가하여 특정 프로젝트 내에서만 사용할 수 있는 이미지이고,   
공용 이미지는 관리자가 추가하여 모든 프로젝트에서 공통적으로 사용할 수 있는 이미지입니다.

## 이미지 상세
목록에서 이미지 이름을 클릭하면 상세 화면으로 이동합니다. 상세 화면에서는 이미지의 기본 정보와 함께 이미지에서 감지한 **OS 정보**, **게스트 기능(cloud-init·qemu-guest-agent) 설치 여부**를 확인할 수 있습니다.

### 상세 정보
| 항목 | 설명 |
| --- | --- |
| **이름** | 이미지 이름입니다. |
| **ID** | 이미지 고유 ID입니다. |
| **분류** | `프로젝트 이미지` 또는 `공용 이미지`입니다. |
| **OS 타입** | 이미지의 OS 타입(Variant)입니다. |
| **OS 이름** | 이미지에서 감지한 운영체제 이름입니다. |
| **OS 버전** | 이미지에서 감지한 운영체제 버전입니다. |
| **OS 아키텍처** | 이미지에서 감지한 아키텍처입니다. |
| **크기** | 이미지 파일 크기입니다. |
| **스토리지 도메인** | 이미지가 저장된 스토리지 도메인입니다. |
| **부팅 펌웨어** | 업로드 시 선언한 부팅 펌웨어(`BIOS`/`UEFI`/`지정 안 함`)입니다. |
| **cloud-init** | cloud-init 설치 여부입니다. (아래 게스트 기능 표 참고) |
| **qemu-guest-agent** | qemu-guest-agent 설치 여부입니다. (아래 게스트 기능 표 참고) |
| **생성 일시** | 이미지를 추가한 일시입니다. |

### 게스트 기능 표시
`cloud-init`과 `qemu-guest-agent`는 이미지 내부를 검사해 감지한 결과를 다음 3가지 상태로 표시합니다.

| 상태 | 의미 |
| --- | --- |
| **설치됨** | 해당 게스트 기능이 이미지에 설치되어 있습니다. |
| **미설치** | 해당 게스트 기능이 이미지에 설치되어 있지 않습니다. |
| **미확인** | 검사로 설치 여부를 판별하지 못한 상태입니다. |

> 💡 **참고:** 게스트 기능은 이미지를 **업로드**하거나 **스냅샷에서 이미지를 생성(캡처)**할 때 이미지를 오프라인으로 검사해 판별합니다. 검사가 아직 끝나지 않았거나 이미지 형식상 판별할 수 없으면 `미확인`으로 표시됩니다. **이미지를 복제**한 경우에는 원본의 게스트 기능 값을 그대로 이어받으며 다시 검사하지 않습니다(원본이 `미확인`이면 복제본도 `미확인`으로 남습니다).
>
> - **cloud-init**: 인스턴스 생성 시 사용자 계정·SSH 키·초기 스크립트 등 초기화 설정을 게스트에 주입하는 데 사용됩니다.
> - **qemu-guest-agent**: 게스트 상태 조회, 안전한 종료·재부팅, 라이브 작업 등 호스트와 게스트 간 연동에 사용됩니다.

> 💡 **참고:** 관리자 영역의 **공용 이미지 관리**에서도 동일한 상세 화면으로 공용 이미지의 OS 정보와 게스트 기능을 확인할 수 있습니다.

## 이미지 업로드
### 기본 정보
- **스토리지 도메인**: 이미지가 저장될 스토리지 도메인을 선택합니다.
- **이미지 파일**: `.qcow2`, `.img` 확장자의 운영체제(OS) 이미지 파일을 업로드합니다.
- **부팅 펌웨어**: 이미지에 선언할 부팅 펌웨어를 `지정 안 함`, `BIOS`, `UEFI` 중에서 선택합니다.

### 입력 필드 유효성
| 필드 | 허용 값 | 검증 규칙 | 비고 |
| --- | --- | --- | --- |
| **스토리지 도메인** | 현재 프로젝트에서 선택 가능한 스토리지 도메인 | 필수입니다. 1개를 선택합니다. | 저장 위치입니다. |
| **이미지 파일** | `.qcow2`, `.img` 파일 | 필수입니다. 파일을 선택해야 합니다. | 업로드 대상입니다. |
| **부팅 펌웨어** | `지정 안 함`, `BIOS`, `UEFI` | 선택 항목입니다. 기본값은 `지정 안 함`입니다. | 지정 안 함으로 두면 이미지에 펌웨어를 선언하지 않습니다. `BIOS` 또는 `UEFI`를 선택하면 해당 값이 이 이미지로 인스턴스를 생성할 때 기본 부팅 펌웨어로 사용됩니다. |

### 업로드 시 참고 사항
- 스토리지 도메인과 이미지 파일을 모두 선택하면 `업로드` 버튼이 활성화됩니다.
- 선택한 스토리지 도메인의 **가용 용량이 부족한 것으로 확인되면 업로드가 사전에 차단**됩니다. 이때 `업로드` 버튼이 비활성화되고 `선택한 스토리지 도메인의 가용 용량이 부족합니다. (필요 …MB, 가용 …MB)` 안내가 표시됩니다. 다른 창을 다녀오면 최신 가용 용량으로 다시 확인합니다. (가용 용량 조회에 실패한 경우에는 사전 차단하지 않습니다.)
- 이미지 업로드는 비동기로 처리됩니다. 업로드를 시작하면 목록에 이미지가 `생성 중`으로 표시되고, 파일 복사·변환이 끝나면 실제 크기로 전환됩니다. 프로젝트 이미지와 공용 이미지 모두 동일하게 동작합니다.
- `생성 중`인 이미지는 인스턴스 생성의 부팅 소스로 선택할 수 없으며, 복제·삭제도 변환이 완료된 뒤에 할 수 있습니다.
- 변환에 실패하면 `생성 중`이던 이미지는 목록에서 자동으로 제거됩니다.

### 이미지 활용
- **가상머신 > 인스턴스 생성**에서 인스턴스 생성을 위한 OS 이미지로 활용합니다.
- **가상머신 > 시작 템플릿**에서 인스턴스 템플릿 생성을 위한 OS 이미지로 활용합니다.

## 이미지 복제
1. 목록에서 복제할 이미지를 선택합니다.
2. `복제`를 클릭합니다.
3. 대상 스토리지 도메인을 선택합니다.
4. 복제를 실행합니다.

> ⚠️ **주의:** 원본 이미지와 동일한 스토리지 도메인은 복제 대상으로 선택할 수 없습니다.
---
## 이미지 삭제
1. 목록에서 삭제할 이미지를 선택합니다.
2. `삭제`를 클릭합니다.
3. 삭제 확인 창에서 내용을 확인한 뒤 삭제를 진행합니다.

> ⚠️ **주의:** 프로젝트 영역에서는 `프로젝트 이미지`만 삭제할 수 있습니다. `공용 이미지`는 관리자 영역의 **공용 이미지 관리**에서 삭제할 수 있습니다.
