# 선호도 그룹

**선호도 그룹**은 여러 가상머신의 배치 위치를 제어하기 위한 도구입니다.

선호도 그룹을 정의하여 지정한 가상머신들을 같은 물리 호스트에 함께 배치하거나, 혹은 반대로 서로 다른 호스트에 배치되도록 하는 규칙을 정할 수 있습니다.

또한 호스트 단위의 선호도 설정을 통해 특정 가상머신들이 지정된 호스트에서만 실행되거나 혹은 피하도록 설정할 수도 있습니다.

## 선호도 그룹 목록

### 주요 작업
- `생성`: 새 선호도 그룹을 만듭니다.
- `편집`: 선택한 선호도 그룹을 편집합니다.
- `삭제`: 선택한 선호도 그룹을 삭제합니다.

선호도 그룹 목록 화면에서는 프로젝트 내 선호도 그룹을 확인하고 관리할 수 있습니다.

### 테이블 컬럼

| 컬럼 | 설명 |
| --- | --- |
| **이름** | 선호도 그룹의 이름입니다. |
| **ID** | 선호도 그룹의 고유 식별자입니다. |
| **활성화 여부** | 선호도 그룹의 활성화 여부입니다. |
| **설명** | 선호도 그룹의 설명입니다. |
| **생성 일시** | 선호도 그룹의 생성 날짜와 시각입니다. |

## 선호도 그룹 상세

선호도 그룹 목록에서 선호도 그룹의 이름을 선택하면 **선호도 그룹 상세** 화면으로 이동합니다. 상단에는 해당 선호도 그룹의 정보가 **[기본 정보]**, **[선호도 규칙]** 2개 박스로 나뉘어 표시됩니다.

### 기본 정보

- **이름**: 선호도 그룹의 이름을 표시합니다.
- **ID**: 선호도 그룹의 고유 식별자를 표시합니다.
- **활성화 여부** : 선호도 그룹의 활성화 여부를 `활성화` 또는 `비활성화`로 표시합니다.
- **설명**: 선호도 그룹에 대한 설명을 표시합니다.
- **생성 일시** : 선호도 그룹을 생성한 날짜와 시간입니다.

### 선호도 규칙

- **가상머신 선호도** : 선호도 그룹의 대상 가상머신을 함께 배치할지 분산 배치할지 표시합니다. 설정하지 않았으면 `사용 안 함`으로 표시됩니다.
- **가상머신 강제성**: 가상머신 선호도 규칙을 강제할지 여부를 표시합니다. 설정하지 않았으면 `사용 안 함`으로 표시됩니다.
- **물리 머신 선호도** : 선호도 그룹의 대상 가상머신이 대상 물리 머신을 선호할지 기피할지 표시합니다. 설정하지 않았으면 `사용 안 함`으로 표시됩니다.
- **물리 머신 강제성** : 물리 머신 선호도 규칙을 강제할지 여부를 표시합니다. 설정하지 않았으면 `사용 안 함`으로 표시됩니다.

### 하단 탭
- **가상머신**: 규칙 적용 대상 인스턴스를 확인합니다.
- **물리 머신**: 물리 머신 선호도 규칙의 기준이 되는 호스트를 확인합니다.

> 💡 **참고:** 두 탭 모두 페이지당 5개씩 표시되며, 별도의 검색창은 없습니다.

### 가상머신 탭

| 컬럼 | 설명 |
| --- | --- |
| **이름** | 가상머신의 이름입니다. 클릭하면 인스턴스 상세 화면으로 이동합니다. |
| **ID** | 가상머신의 고유 식별자입니다. |
| **IP 주소** | 인스턴스에 할당된 IP 주소입니다. 여러 개면 쉼표로 함께 표시됩니다. |
| **상태** | 인스턴스의 작동 상태입니다. **실행 중**, **종료됨**, **재부팅 중**, **마이그레이션 중** 등 현재 상태가 한글로 표시됩니다. |
| **vCPU** | 인스턴스에 할당된 가상 CPU 코어 수입니다. |
| **메모리** | 인스턴스에 할당된 메모리 용량입니다. |
| **생성 일시** | 인스턴스가 최초로 생성된 날짜와 시간입니다. |

### 가상머신 대상 편집

선호도 그룹 상세 페이지의 가상머신 탭에서 `편집`을 클릭하여 선호도 그룹의 규칙을 적용할 **가상머신 대상**을 편집할 수 있습니다.

편집 화면에서는 다음 순서로 대상을 변경합니다.

1. `추가`를 클릭하면 인스턴스 선택 모달이 열립니다. 대상 가상머신을 골라 목록에 추가합니다.
2. 목록에서 제외할 가상머신을 선택하고 `삭제`를 클릭하면 목록에서 빠집니다. 1개 이상 선택해야 `삭제`가 활성화되며, 여러 건을 한 번에 선택할 수 있습니다.
3. `저장`을 클릭하면 변경한 대상 목록이 반영되고 상세 화면으로 돌아갑니다.
4. `취소`를 클릭하면 변경을 반영하지 않고 상세 화면으로 돌아갑니다.

> 💡 **참고:** 편집 화면의 목록은 페이지당 10개씩 표시됩니다. `삭제`는 목록에서만 제외하는 것이며, `저장`을 눌러야 실제로 반영됩니다.

> ⚠️ **주의** : 선호도 그룹의 설정이 다른 선호도 그룹의 설정과 충돌하는 경우 오류를 표시하여 잘못된 구성을 방지합니다.

### 물리 머신 탭

| 컬럼 | 설명 |

| **이름** | 물리 머신의 이름입니다. |
| **ID** | 물리 머신의 고유 식별자입니다. |
| **생성 일시** | 물리 머신이 최초로 생성된 날짜와 시간입니다. |

### 물리 머신 대상 편집

선호도 그룹 상세 페이지의 물리 머신 탭에서 `편집`을 클릭하여 선호도 그룹의 규칙의 기준이 되는 **물리 머신 대상**을 편집할 수 있습니다.

동선은 가상머신 대상 편집과 같습니다.

1. `추가`를 클릭하면 물리 머신 선택 모달이 열립니다. 기준이 될 물리 머신을 골라 목록에 추가합니다.
2. 목록에서 제외할 물리 머신을 선택하고 `삭제`를 클릭하면 목록에서 빠집니다. 1개 이상 선택해야 `삭제`가 활성화되며, 여러 건을 한 번에 선택할 수 있습니다.
3. `저장`을 클릭하면 변경한 대상 목록이 반영되고 상세 화면으로 돌아갑니다.
4. `취소`를 클릭하면 변경을 반영하지 않고 상세 화면으로 돌아갑니다.

> ⚠️ **주의** : 선호도 그룹의 설정이 다른 선호도 그룹의 설정과 충돌하는 경우 오류를 표시하여 잘못된 구성을 방지합니다.

## 선호도 그룹 생성 및 편집

선호도 그룹 생성 화면과 편집 화면은 동일한 양식으로 구성되어 있으며, 선호도 그룹의 각종 설정 값을 입력할 수 있습니다.

### 기본 정보
- **이름**: 선호도 그룹의 이름을 입력합니다. 최대 80자까지 입력할 수 있습니다.
- **설명**: 선호도 그룹에 대한 설명을 입력합니다.
- **활성화 여부** : 선호도 그룹의 활성화 여부입니다. `활성화`/`비활성화` 토글이며 생성 화면 기본값은 `활성화`입니다.

### 입력 필드 유효성

| 필드 | 허용 값 및 길이 | 검증 규칙 | 비고 |
|------|------------------|------------|------|
| **이름** | 영문 대소문자, 숫자 / 최대 80자 | 공백 불가, 영문 대소문자, 숫자, `-`, `_`  | 필수 입력 |
| **설명** | 모든 문자 / 최대 200자 | 형식 제한 없음 | 선택 입력 |
| **활성화 여부** | `활성화`, `비활성화` | 생성 시 기본값 `활성화` | 필수 입력 |

### 가상머신 선호도 규칙
- **가상머신 선호도** : 선호도 그룹의 대상 가상머신들을 함께 배치할지 분산 배치할지 결정합니다. `선호도`, `반선호도`, `사용 안 함` 중 하나를 선택하며, `사용 안 함` 설정 시 가상머신에 대한 선호도를 적용하지 않습니다.
- **가상머신 강제성**: **가상머신 선호도** 규칙을 강제할지 여부를 결정합니다. `강제`, `비강제` 중 하나를 선택합니다. `강제` 설정한 경우 대상 가상머신 실행 시 선호도 그룹의 규칙을 만족하는 물리 머신이 없다면 실행에 실패합니다.

### 물리 머신 선호도 규칙
- **물리 머신 선호도** : 물리 머신에 대한 선호도 규칙으로 대상 물리 머신을 선호할지 기피할지 결정합니다. `선호도`, `반선호도`, `사용 안 함` 중 하나를 선택하며, `사용 안 함` 설정 시 물리 머신에 대한 선호도를 적용하지 않습니다.
- **물리 머신 강제성** : **물리 머신 선호도** 규칙을 강제할지 여부를 결정합니다. `강제`, `비강제` 중 하나를 선택합니다. `강제` 설정한 경우 대상 가상머신 실행 시 선호도 그룹의 규칙을 만족하는 물리 머신이 없다면 실행에 실패합니다.

> 💡 **참고:** 선호도와 강제성은 서로 연동됩니다. 선호도를 `사용 안 함`으로 두면 같은 줄의 강제성 선택이 비활성화되고, 선호도를 `선호도` 또는 `반선호도`로 바꾸면 강제성이 자동으로 `비강제`로 설정됩니다. 가상머신과 물리 머신이 각각 따로 동작합니다.

### 선호도 그룹 대상 추가
- **가상머신** : 선호도 그룹의 규칙을 적용할 가상머신을 선택합니다.
- **물리 머신** :  선호도 그룹의 가상머신이 물리 머신 선호도 규칙으로 제한할 물리 머신을 선택합니다.

입력을 완료한 후 `생성` 버튼을 클릭하여 선호도 그룹을 생성합니다.

### 생성/편집 시 주의 사항
- 이미 실행 중인 가상머신은 선호도 그룹의 규칙에 영향을 받지 않으며, 다음 실행 시 선호도 그룹의 규칙에 의해 해당 가상머신을 실행할 물리 머신이 결정됩니다.
- `가상머신 선호도/반선호도` `강제` 선호도 규칙은 해당 선호도 그룹에 속한 인스턴스의 실행 위치가 결정된 이후에 다른 인스턴스의 실행 위치에 영향을 줄 수 있습니다.
- 생성/편집 시 선호도 그룹 사이의 규칙 충돌 여부를 검사하며, 규칙이 충돌하는 경우 생성/편집할 수 없습니다.
- `비활성화` 상태의 선호도 그룹은 규칙 충돌과 관계없이 생성/편집이 가능합니다.

### 선호도 규칙 충돌 기준
- 충돌 검사는 동일한 가상머신/물리 머신을 대상으로 하는 `활성화` 상태의 선호도 그룹의 `강제` 규칙만 대상으로 합니다.
- 인스턴스 `선호도/강제` vs 인스턴스 `반선호도/강제`: 동일한 두 개 이상의 인스턴스를 대상으로 하는 선호도/반선호도 규칙이 동시에 존재하면 충돌
- 물리 머신 `선호도/강제` vs 물리 머신 `반선호도/강제`: 동일한 인스턴스에 대해 동일한 물리 머신에 대한 선호도/반선호도 규칙이 동시에 존재하면 충돌
- 인스턴스 `반선호도/강제` vs 물리 머신 `선호도/강제`: 반선호도 대상 인스턴스들 가운데 물리 머신 선호도로 호스트가 제한된 인스턴스들을 서로 다른 허용 호스트에 하나씩 배정할 수 없으면 충돌 (예: 허용 호스트가 `A` 하나뿐인 인스턴스 2대. 인스턴스 3대에 허용 호스트 3대처럼 분산 배치가 가능한 구성은 충돌이 아님). 여러 물리 머신 선호도 그룹에 속한 인스턴스의 허용 호스트는 그 그룹들의 교집합으로 계산
- 물리 머신 `선호도/강제` vs 물리 머신 `선호도/강제`: 동일한 인스턴스에 대해 서로 다른 물리 머신에 대한 물리 머신 선호도 규칙이 다수 존재하면 충돌

## 선호도 그룹 삭제

선호도 그룹 목록에서 `삭제`를 선택하여 선호도 그룹을 삭제할 수 있습니다.

> 💡 **참고:** 선호도 그룹을 삭제해도 선호도 그룹의 가상머신들은 즉시 종료되거나 이동하지는 않습니다. 향후 해당 가상머신들의 배치에는 더 이상 해당 그룹의 규칙이 적용되지 않습니다.
