# 로그인

## 화면 개요

웹콘솔에 들어갈 때 처음 보는 화면입니다. `ID`와 `비밀번호`로 로그인하고, 계정 상태에 따라 일회용 코드 입력, OTP 등록, 계정 정보 입력 단계가 이어집니다. 관리자 멤버와 프로젝트 멤버가 같은 화면을 씁니다.

화면 아래쪽에는 제품 버전(예: `Cloud:iA v1.0`)이 표시됩니다. 빌드 날짜가 붙은 버전은 로그인한 뒤 [버전 정보](../my-info/my-info.md#버전-정보)에서 확인합니다.

## 로그인하기

1. `ID`와 `비밀번호`를 입력합니다.
2. `로그인`을 클릭합니다.
3. 추가 단계가 없으면 바로 웹콘솔 첫 화면으로 이동합니다. 계정 상태에 따라 아래 화면이 이어질 수 있습니다.

| 계정 상태 | 이어지는 화면 |
| --- | --- |
| OTP를 등록한 계정 | [일회용 코드 입력](#일회용-코드-입력) |
| OTP 정책이 켜져 있는데 아직 OTP를 등록하지 않은 계정 | [OTP 등록](#otp-등록) |
| 사용자 정보나 비밀번호를 갱신해야 하는 계정 | [계정 정보 입력](#계정-정보-입력) |

### 로그인에 실패하면

- ID나 비밀번호가 맞지 않으면 `로그인에 실패했습니다. 로그인 시도가 반복되면 일시적으로 로그인이 제한될 수 있습니다.`가 표시됩니다. ID가 없는 경우, 비밀번호가 틀린 경우, 계정이 잠긴 경우를 구분하지 않고 같은 문구를 보여 줍니다.
- 실패가 반복되면 정해진 시간 동안 로그인이 제한됩니다. 기준 횟수와 제한 시간은 관리자가 [정책 설정](../../administrator/setting/policy-setting/policy-setting.md)에서 정합니다.
- 추가 단계를 진행하다가 시간이 지나 만료되면 `로그인 시간이 만료되었습니다. 다시 로그인을 시도하세요.`가 표시됩니다. 처음부터 다시 로그인합니다.

### 외부 계정으로 로그인

SSO 연동을 켠 설치에서는 로그인 버튼 아래에 `Microsoft 계정으로 로그인` 버튼이 보입니다. SSO 연동을 쓰지 않으면 이 버튼은 나오지 않습니다. 외부 계정으로 처음 로그인할 때의 계정 연결 절차는 관리자 매뉴얼의 [SSO 연동](../../administrator/setting/sso/sso.md)을 참고하세요.

외부 계정 로그인이 실패하면 로그인 화면으로 돌아오고 `SSO 로그인에 실패했습니다. 다시 시도해 주세요.`가 표시됩니다.

## 일회용 코드 입력

OTP를 등록한 계정은 비밀번호 다음에 이 화면이 나옵니다.

1. 휴대폰의 인증 앱에서 Cloud:iA 계정의 코드를 확인합니다.
2. `일회용 코드`에 코드를 입력합니다.
3. `로그인`을 클릭합니다.

처음 화면으로 돌아가려면 `로그인으로 돌아가기`를 클릭합니다.

## OTP 등록

OTP 정책이 켜져 있는데 아직 OTP를 등록하지 않은 계정은 로그인할 때 OTP를 먼저 등록해야 합니다. 화면 위에 `계정을 활성화하려면 모바일 인증기를 설정해야 합니다.` 안내가 표시됩니다.

1. 화면에 나온 인증 앱 가운데 하나를 휴대폰에 설치합니다.
2. 앱을 열고 화면의 바코드를 스캔합니다.
   - 바코드를 스캔할 수 없으면 `스캔할 수 없습니까?`를 클릭합니다. `계정명(Codename)`과 `시크릿 키`가 표시되며, 앱에 이 값을 직접 입력합니다. `설정 키 복사`로 시크릿 키를 복사할 수 있습니다.
   - 앱이 지원하면 화면에 나온 `OTP 해시 알고리즘`, `OTP 자리 수`, `OTP 주기(초)`도 같은 값으로 설정합니다.
   - 보안 설정에 따라 `보안 설정에 따라 QR 코드 스캔으로만 등록할 수 있습니다.`가 표시되면 바코드 스캔으로만 등록할 수 있습니다.
3. 앱에 나온 일회용 코드를 입력하고 `제출`을 클릭합니다.

등록이 끝나면 바로 로그인됩니다. 다음 로그인부터는 [일회용 코드 입력](#일회용-코드-입력) 화면이 나옵니다. OTP 정책은 관리자 매뉴얼의 [정책 설정](../../administrator/setting/policy-setting/policy-setting.md#otp)을 참고하세요.

## 계정 정보 입력

사용자 정보나 비밀번호를 갱신해야 하는 계정은 로그인 전에 이 화면에서 정보를 먼저 입력합니다. 관리자가 만든 멤버는 첫 로그인 때 비밀번호 변경, 사용자 정보 입력 순서로 이 화면이 나오고, OTP 정책이 켜져 있으면 이어서 [OTP 등록](#otp-등록) 화면이 나옵니다.

- **사용자 정보**: 화면 위에 `계정을 활성화하려면 사용자 정보를 업데이트해야 합니다.` 안내가 표시됩니다. `이름`과 `이메일`은 잠겨 있어 확인만 하고, `휴대폰 번호`를 입력한 뒤 `저장`을 클릭합니다.
- **비밀번호**: `새 비밀번호`와 `비밀번호 확인`을 입력하고 `저장`을 클릭합니다. 입력란 아래에 비밀번호 정책(`최소 길이`, `대문자 개수`, `특수 문자 개수` 등)을 지켰는지 표시됩니다.

저장하면 다음 단계로 넘어가거나 로그인이 완료됩니다. 처음 화면으로 돌아가려면 `로그인으로 돌아가기`를 클릭합니다.
