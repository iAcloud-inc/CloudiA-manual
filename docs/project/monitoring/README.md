# 모니터링

프로젝트 `모니터링` 메뉴는 현재 프로젝트 범위에서 발생한 이벤트를 확인하고, 인스턴스 자원 사용량 기반 알림 규칙을 관리하는 영역입니다. 인스턴스, 네트워크, 스토리지 작업 중 발생한 주요 이벤트를 프로젝트 관점에서 조회하거나, 인스턴스 사용률 조건에 따른 자동 알림을 설정할 때 사용합니다.

## 구성 메뉴
- **이벤트**: 현재 프로젝트에 속한 이벤트를 시간순으로 조회합니다.
- **이벤트 트리거**: 인스턴스 CPU·메모리 사용률 조건을 설정해 충족 시 이메일 알림을 받습니다.

## 참고 사항
- 관리자 영역의 `이벤트`와 달리 프로젝트 범위로 제한된 데이터만 보여줍니다.
- 상세 원인 분석이 필요하면 네트워크, 가상머신, 스토리지 메뉴와 함께 교차 확인하는 것이 좋습니다.
